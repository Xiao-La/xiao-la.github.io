线性变换将一个向量空间映射到另一个向量空间 <span class="course-math" data-tex="\mathbf{T}:V\to W" data-display="false"><code>\mathbf{T}:V\to W</code></span>，它满足这两个条件：
<span class="course-math course-math-display" data-tex="\text{1. }\mathbf{T}(a+b)=\mathbf{T}(a)+\mathbf{T}(b)" data-display="true"><code>\text{1. }\mathbf{T}(a+b)=\mathbf{T}(a)+\mathbf{T}(b)</code></span>
<span class="course-math course-math-display" data-tex="\text{2. }\mathbf{T}(ka)=k\mathbf{T}(a)" data-display="true"><code>\text{2. }\mathbf{T}(ka)=k\mathbf{T}(a)</code></span>
线性变换可以用矩阵表示，其定义如下：
设 <span class="course-math" data-tex="V" data-display="false"><code>V</code></span> 和 <span class="course-math" data-tex="W" data-display="false"><code>W</code></span> 是同一个数域 <span class="course-math" data-tex="F" data-display="false"><code>F</code></span> 上的有限维向量空间，且 <span class="course-math" data-tex="\dim(V) = n" data-display="false"><code>\dim(V) = n</code></span>，<span class="course-math" data-tex="\dim(W) = m" data-display="false"><code>\dim(W) = m</code></span>。设 <span class="course-math" data-tex="T: V \to W" data-display="false"><code>T: V \to W</code></span> 是一个从 <span class="course-math" data-tex="V" data-display="false"><code>V</code></span> 到 <span class="course-math" data-tex="W" data-display="false"><code>W</code></span> 的线性变换。设 <span class="course-math" data-tex="\alpha_1, \alpha_2, \dots, \alpha_n" data-display="false"><code>\alpha_1, \alpha_2, \dots, \alpha_n</code></span> 是定义域 <span class="course-math" data-tex="V" data-display="false"><code>V</code></span> 的一组基， <span class="course-math" data-tex="\beta_1, \beta_2, \dots, \beta_m" data-display="false"><code>\beta_1, \beta_2, \dots, \beta_m</code></span> 是目标域 <span class="course-math" data-tex="W" data-display="false"><code>W</code></span> 的一组基。那么 <span class="course-math" data-tex="T(\alpha_j)" data-display="false"><code>T(\alpha_j)</code></span> 可以唯一地表示为这些基向量的线性组合：
<span class="course-math course-math-display" data-tex="T(\alpha_j) = a_{1j}\beta_1 + a_{2j}\beta_2 + \dots + a_{mj}\beta_m = \sum_{i=1}^m a_{ij}\beta_i" data-display="true"><code>T(\alpha_j) = a_{1j}\beta_1 + a_{2j}\beta_2 + \dots + a_{mj}\beta_m = \sum_{i=1}^m a_{ij}\beta_i</code></span>
我们将上述 <span class="course-math" data-tex="n" data-display="false"><code>n</code></span> 个等式（<span class="course-math" data-tex="j=1, 2, \dots, n" data-display="false"><code>j=1, 2, \dots, n</code></span>）中的系数 <span class="course-math" data-tex="a_{ij}" data-display="false"><code>a_{ij}</code></span> 排列成一个 <span class="course-math" data-tex="m \times n" data-display="false"><code>m \times n</code></span> 的矩阵 <span class="course-math" data-tex="A" data-display="false"><code>A</code></span>。具体来说，把 <span class="course-math" data-tex="T(\alpha_j)" data-display="false"><code>T(\alpha_j)</code></span> 在基 <span class="course-math" data-tex="\beta" data-display="false"><code>\beta</code></span> 下的坐标列向量作为矩阵 <span class="course-math" data-tex="A" data-display="false"><code>A</code></span> 的第 <span class="course-math" data-tex="j" data-display="false"><code>j</code></span> 列：

<span class="course-math course-math-display" data-tex="A = \begin{pmatrix} &#10;a_{11} &amp; a_{12} &amp; \dots &amp; a_{1n} \\ &#10;a_{21} &amp; a_{22} &amp; \dots &amp; a_{2n} \\ &#10;\vdots &amp; \vdots &amp; \ddots &amp; \vdots \\ &#10;a_{m1} &amp; a_{m2} &amp; \dots &amp; a_{mn} &#10;\end{pmatrix}" data-display="true"><code>A = \begin{pmatrix} &#10;a_{11} &amp; a_{12} &amp; \dots &amp; a_{1n} \\ &#10;a_{21} &amp; a_{22} &amp; \dots &amp; a_{2n} \\ &#10;\vdots &amp; \vdots &amp; \ddots &amp; \vdots \\ &#10;a_{m1} &amp; a_{m2} &amp; \dots &amp; a_{mn} &#10;\end{pmatrix}</code></span>

这个矩阵 <span class="course-math" data-tex="A" data-display="false"><code>A</code></span> 就称为**线性变换 <span class="course-math" data-tex="T" data-display="false"><code>T</code></span> 在基 <span class="course-math" data-tex="\alpha" data-display="false"><code>\alpha</code></span> 和基 <span class="course-math" data-tex="\beta" data-display="false"><code>\beta</code></span> 下的矩阵表示**。
上述关系通常可以用分块矩阵的形式简记为：
<span class="course-math course-math-display" data-tex="T(\alpha_1, \alpha_2, \dots, \alpha_n) = (\beta_1, \beta_2, \dots, \beta_m) A" data-display="true"><code>T(\alpha_1, \alpha_2, \dots, \alpha_n) = (\beta_1, \beta_2, \dots, \beta_m) A</code></span>

矩阵表示的意义：如果 <span class="course-math" data-tex="V" data-display="false"><code>V</code></span> 中的向量 <span class="course-math" data-tex="v" data-display="false"><code>v</code></span> 在基 <span class="course-math" data-tex="\alpha" data-display="false"><code>\alpha</code></span> 下的坐标列向量为 <span class="course-math" data-tex="x = (x_1, x_2, \dots, x_n)^T" data-display="false"><code>x = (x_1, x_2, \dots, x_n)^T</code></span>；其像 <span class="course-math" data-tex="T(v)" data-display="false"><code>T(v)</code></span> 在 <span class="course-math" data-tex="W" data-display="false"><code>W</code></span> 的基 <span class="course-math" data-tex="\beta" data-display="false"><code>\beta</code></span> 下的坐标列向量为 <span class="course-math" data-tex="y = (y_1, y_2, \dots, y_m)^T" data-display="false"><code>y = (y_1, y_2, \dots, y_m)^T</code></span>。那么，抽象的线性变换 <span class="course-math" data-tex="T(v)" data-display="false"><code>T(v)</code></span> 等价于其坐标向的矩阵乘法 <span class="course-math" data-tex="y = Ax" data-display="false"><code>y = Ax</code></span>。



**旋转矩阵**
<span class="course-math course-math-display" data-tex="T_{\theta}=\begin{bmatrix}&#10;\cos\theta &amp; -\sin\theta \\&#10;\sin\theta &amp; \cos\theta&#10;\end{bmatrix}" data-display="true"><code>T_{\theta}=\begin{bmatrix}&#10;\cos\theta &amp; -\sin\theta \\&#10;\sin\theta &amp; \cos\theta&#10;\end{bmatrix}</code></span>
表示将 <span class="course-math" data-tex="\mathbb{R}^{2}" data-display="false"><code>\mathbb{R}^{2}</code></span> 的基向量 <span class="course-math" data-tex="\mathbf{i}=(1,0),\mathbf{j}=(0,1)" data-display="false"><code>\mathbf{i}=(1,0),\mathbf{j}=(0,1)</code></span> 绕原点逆时针旋转 <span class="course-math" data-tex="\theta" data-display="false"><code>\theta</code></span> ：
<span class="course-math course-math-display" data-tex="\mathbf{i}&#x27;=\mathbf{T_{\theta}}(\mathbf{i})=T_{\theta}\begin{bmatrix}&#10;1 \\&#10;0&#10;\end{bmatrix}=\begin{bmatrix}&#10;\cos\theta \\&#10;\sin\theta &#10;\end{bmatrix}" data-display="true"><code>\mathbf{i}&#x27;=\mathbf{T_{\theta}}(\mathbf{i})=T_{\theta}\begin{bmatrix}&#10;1 \\&#10;0&#10;\end{bmatrix}=\begin{bmatrix}&#10;\cos\theta \\&#10;\sin\theta &#10;\end{bmatrix}</code></span>
<span class="course-math course-math-display" data-tex="\mathbf{j}&#x27;= \mathbf{T_{\theta}}(\mathbf{j})=T_{\theta}\begin{bmatrix}&#10;0 \\&#10;1&#10;\end{bmatrix}&#10;=\begin{bmatrix}&#10;-\sin\theta \\&#10;\cos\theta &#10;\end{bmatrix}" data-display="true"><code>\mathbf{j}&#x27;= \mathbf{T_{\theta}}(\mathbf{j})=T_{\theta}\begin{bmatrix}&#10;0 \\&#10;1&#10;\end{bmatrix}&#10;=\begin{bmatrix}&#10;-\sin\theta \\&#10;\cos\theta &#10;\end{bmatrix}</code></span>
**投影矩阵**
<span class="course-math course-math-display" data-tex="P_{\theta}=\begin{bmatrix}&#10;\cos ^{2}\theta &amp; \cos\theta \sin\theta \\&#10;\cos\theta \sin\theta &amp; \sin ^{2}\theta&#10;\end{bmatrix}" data-display="true"><code>P_{\theta}=\begin{bmatrix}&#10;\cos ^{2}\theta &amp; \cos\theta \sin\theta \\&#10;\cos\theta \sin\theta &amp; \sin ^{2}\theta&#10;\end{bmatrix}</code></span>
表示将 <span class="course-math" data-tex="\mathbb{R}^{2}" data-display="false"><code>\mathbb{R}^{2}</code></span> 的基向量 <span class="course-math" data-tex="\mathbf{i}=(1,0),\mathbf{j}=(0,1)" data-display="false"><code>\mathbf{i}=(1,0),\mathbf{j}=(0,1)</code></span> 投影到 <span class="course-math" data-tex="\mathbf{v}=(\cos\theta, \sin\theta)" data-display="false"><code>\mathbf{v}=(\cos\theta, \sin\theta)</code></span> 上。

**反射矩阵**
<span class="course-math" data-tex="\mathbf{R}_{\theta}:\mathbb{R}^{2}\to \mathbb{R}^{2}" data-display="false"><code>\mathbf{R}_{\theta}:\mathbb{R}^{2}\to \mathbb{R}^{2}</code></span> 表示向量由 <span class="course-math" data-tex="\mathbf{v}=(\cos\theta, \sin\theta)" data-display="false"><code>\mathbf{v}=(\cos\theta, \sin\theta)</code></span> 反射。由几何关系有
<span class="course-math course-math-display" data-tex="\mathbf{R}_{\theta}(\mathbf{v})+\mathbf{v}=2\mathbf{P}_{\theta}(\mathbf{v})" data-display="true"><code>\mathbf{R}_{\theta}(\mathbf{v})+\mathbf{v}=2\mathbf{P}_{\theta}(\mathbf{v})</code></span>
那么就有
<span class="course-math course-math-display" data-tex="R_{\theta}=2P_{\theta}-I=\begin{bmatrix}&#10;\cos(2\theta) &amp; \sin(2\theta) \\&#10;\sin(2\theta) &amp; -\cos(2\theta)&#10;\end{bmatrix}" data-display="true"><code>R_{\theta}=2P_{\theta}-I=\begin{bmatrix}&#10;\cos(2\theta) &amp; \sin(2\theta) \\&#10;\sin(2\theta) &amp; -\cos(2\theta)&#10;\end{bmatrix}</code></span>

这里的变换矩阵和**基的选取**有关。
线性变换的变换基（Change of basis）：若 <span class="course-math" data-tex="\mathbf{T}:V\to V" data-display="false"><code>\mathbf{T}:V\to V</code></span> 是一个线性变换，而 <span class="course-math" data-tex="A" data-display="false"><code>A</code></span> 是 <span class="course-math" data-tex="\mathbf{T}" data-display="false"><code>\mathbf{T}</code></span> 在基 <span class="course-math" data-tex="\mathbf{v}_{1}, \dots, \mathbf{v}_{n}" data-display="false"><code>\mathbf{v}_{1}, \dots, \mathbf{v}_{n}</code></span> 下的矩阵表示，<span class="course-math" data-tex="B" data-display="false"><code>B</code></span> 是 <span class="course-math" data-tex="\mathbf{T}" data-display="false"><code>\mathbf{T}</code></span>  在基 <span class="course-math" data-tex="\mathbf{w}_{1},\dots, \mathbf{w}_{n}" data-display="false"><code>\mathbf{w}_{1},\dots, \mathbf{w}_{n}</code></span> 下的矩阵表示。
若 <span class="course-math" data-tex="\begin{bmatrix}\mathbf{w}_{1} \dots \mathbf{w}_{n}\end{bmatrix}=\begin{bmatrix}\mathbf{v}_{1}\dots \mathbf{v}_{n}\end{bmatrix}S" data-display="false"><code>\begin{bmatrix}\mathbf{w}_{1} \dots \mathbf{w}_{n}\end{bmatrix}=\begin{bmatrix}\mathbf{v}_{1}\dots \mathbf{v}_{n}\end{bmatrix}S</code></span>，则有 <span class="course-math" data-tex="B=S^{-1}AS" data-display="false"><code>B=S^{-1}AS</code></span>。

**理解：** <span class="course-math" data-tex="Wx=V(Sx)" data-display="false"><code>Wx=V(Sx)</code></span>。也就是说，<span class="course-math" data-tex="W" data-display="false"><code>W</code></span> 基下的坐标 <span class="course-math" data-tex="x" data-display="false"><code>x</code></span> 对应 <span class="course-math" data-tex="V" data-display="false"><code>V</code></span> 基下的坐标 <span class="course-math" data-tex="Sx" data-display="false"><code>Sx</code></span>！所以，在基 <span class="course-math" data-tex="W" data-display="false"><code>W</code></span> 下，线性变换的矩阵表示为 <span class="course-math" data-tex="y=Bx" data-display="false"><code>y=Bx</code></span>，这里 <span class="course-math" data-tex="x,y" data-display="false"><code>x,y</code></span> 都是 <span class="course-math" data-tex="W" data-display="false"><code>W</code></span> 基下的坐标。把 <span class="course-math" data-tex="y=Bx" data-display="false"><code>y=Bx</code></span> 翻译成 <span class="course-math" data-tex="V" data-display="false"><code>V</code></span> 基下的坐标：<span class="course-math" data-tex="Sy=A(Sx)" data-display="false"><code>Sy=A(Sx)</code></span>！对比一下，就可以得到 <span class="course-math" data-tex="B=S^{-1}AS" data-display="false"><code>B=S^{-1}AS</code></span>！
