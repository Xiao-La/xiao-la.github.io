### Propositional Logic（命题逻辑）
{: #section-1 }


**Propositional Symbols:** <span class="course-math" data-tex="P, Q, R\dots" data-display="false"><code>P, Q, R\dots</code></span>
**Logical Connectives:**
1. Not（否定） (<span class="course-math" data-tex="\neg" data-display="false"><code>\neg</code></span>)
2. And（合取） (<span class="course-math" data-tex="\land" data-display="false"><code>\land</code></span>)
3. Or（析取） (<span class="course-math" data-tex="\lor" data-display="false"><code>\lor</code></span>)
4. Exclusive Or（异或） (<span class="course-math" data-tex="\oplus" data-display="false"><code>\oplus</code></span>)
5. Implication（蕴含） (<span class="course-math" data-tex="\to" data-display="false"><code>\to</code></span>)

| <span class="course-math" data-tex="P" data-display="false"><code>P</code></span>   | <span class="course-math" data-tex="Q" data-display="false"><code>Q</code></span>   | <span class="course-math" data-tex="P\to Q" data-display="false"><code>P\to Q</code></span> |
| ----- | ----- | -------- |
| false | false | true     |
| false | true  | true     |
| true  | false | false    |
| true  | true  | true     |

5. Biconditional（双条件/当且仅当） (<span class="course-math" data-tex="\leftrightarrow" data-display="false"><code>\leftrightarrow</code></span>)

| <span class="course-math" data-tex="P" data-display="false"><code>P</code></span>   | <span class="course-math" data-tex="Q" data-display="false"><code>Q</code></span>   | <span class="course-math" data-tex="P\leftrightarrow Q" data-display="false"><code>P\leftrightarrow Q</code></span> |
| ----- | ----- | -------------------- |
| false | false | true                 |
| false | true  | false                |
| true  | false | false                |
| true  | true  | true                 |

**Concepts:** 

- **Sentence:** An assertion in a knowledge representation language.
- **Model:** An assignment of a truth value to every proposition.
- **Knowledge Base (KB):** A set of sentences know by an agent. 
- **Entail（蕴含）：** <span class="course-math" data-tex="\alpha \vDash \beta" data-display="false"><code>\alpha \vDash \beta</code></span> means in **every model** where <span class="course-math" data-tex="\alpha" data-display="false"><code>\alpha</code></span> is true, <span class="course-math" data-tex="\beta" data-display="false"><code>\beta</code></span> is true, too. 
- **Clause（子句）：** A disjunction of literals, e.g. (<span class="course-math" data-tex="P\lor Q\lor R" data-display="false"><code>P\lor Q\lor R</code></span>)
- **Conjunctive normal form (CNF)（合取范式）：** Logical sentence that is a conjunction of clauses, e.g. (<span class="course-math" data-tex="(A\lor B\lor C)\land (D\lor \neg E)\land (F\lor G)" data-display="false"><code>(A\lor B\lor C)\land (D\lor \neg E)\land (F\lor G)</code></span>)



### Model Checking Algorithm（模型检查算法）
{: #section-2 }


To determine if KB entails <span class="course-math" data-tex="\alpha" data-display="false"><code>\alpha</code></span>, we enumerate all possible models, and check if in every model where KB is true, <span class="course-math" data-tex="\alpha" data-display="false"><code>\alpha</code></span> is true as well.

<pre class="course-pseudocode">\begin{algorithm}
  \caption{Model Checking for \texttt{KB} Entailing \texttt{alpha}}
  \begin{algorithmic}
    \Require{A set of propositional atoms \texttt{Atoms}, a knowledge base \texttt{KB} (set of formulas), a formula \texttt{alpha}}
    \Ensure{Return whether \texttt{KB} entails \texttt{alpha}; optionally produce a counterexample valuation}
    \Function{EntailsByModelChecking}{\texttt{KB}, \texttt{alpha}, \texttt{Atoms}}
      \ForAll{\texttt{valuation} in \texttt{GenerateAllValuations(Atoms)}}
        \If{\texttt{SatisfiesKB(valuation, KB)}}
          \If{\texttt{Evaluate(alpha, valuation)} = \texttt{false}}
            \State \Return &quot;Not Entailed&quot; with counterexample \texttt{valuation}
          \EndIf
        \EndIf
      \EndFor
      \State \Return &quot;Entailed&quot;
    \EndFunction

    \Function{SatisfiesKB}{\texttt{valuation}, \texttt{KB}}
      \ForAll{\texttt{phi} in \texttt{KB}}
        \If{\texttt{Evaluate(phi, valuation)} = \texttt{false}}
          \State \Return \texttt{false}
        \EndIf
      \EndFor
      \State \Return \texttt{true}
    \EndFunction

    \Function{GenerateAllValuations}{\texttt{Atoms}}
      \State \texttt{valuations} $\gets$ an iterator over all mappings \texttt{Atoms} $\to$ \{\texttt{true}, \texttt{false}\}
      \State \Return \texttt{valuations}
    \EndFunction

    \Function{Evaluate}{\texttt{formula}, \texttt{valuation}}
      \If{\texttt{IsAtom(formula)}}
        \State \Return \texttt{valuation[formula]}
      \ElsIf{\texttt{IsNegation(formula)}}
        \State \texttt{sub} $\gets$ \texttt{Subformula(formula)}
        \State \Return not \texttt{Evaluate(sub, valuation)}
      \ElsIf{\texttt{IsConjunction(formula)}}
        \State \texttt{left} $\gets$ \texttt{Left(formula)}; \texttt{right} $\gets$ \texttt{Right(formula)}
        \State \Return \texttt{Evaluate(left, valuation)} and \texttt{Evaluate(right, valuation)}
      \ElsIf{\texttt{IsDisjunction(formula)}}
        \State \texttt{left} $\gets$ \texttt{Left(formula)}; \texttt{right} $\gets$ \texttt{Right(formula)}
        \State \Return \texttt{Evaluate(left, valuation)} or \texttt{Evaluate(right, valuation)}
      \ElsIf{\texttt{IsImplication(formula)}}
        \State \texttt{left} $\gets$ \texttt{Left(formula)}; \texttt{right} $\gets$ \texttt{Right(formula)}
        \State \Return (not \texttt{Evaluate(left, valuation)}) or \texttt{Evaluate(right, valuation)}
      \ElsIf{\texttt{IsBiconditional(formula)}}
        \State \texttt{left} $\gets$ \texttt{Left(formula)}; \texttt{right} $\gets$ \texttt{Right(formula)}
        \State \Return \texttt{Evaluate(left, valuation)} = \texttt{Evaluate(right, valuation)}
      \Else
        \State \Return &quot;Unsupported Formula&quot;
      \EndIf
    \EndFunction
  \end{algorithmic}
\end{algorithm}
</pre>


### Inference（推理）
{: #section-3 }


- **Modus Ponens（肯定前件）：** <span class="course-math" data-tex="\displaystyle \dfrac{(\alpha \to \beta,\, \alpha)}{\beta}" data-display="false"><code>\displaystyle \dfrac{(\alpha \to \beta,\, \alpha)}{\beta}</code></span>

- **And Elimination（合取消去）：** <span class="course-math" data-tex="\displaystyle \dfrac{(\alpha \land \beta)}{(\alpha,\, \beta)}" data-display="false"><code>\displaystyle \dfrac{(\alpha \land \beta)}{(\alpha,\, \beta)}</code></span>

- **Double Negation Elimination（双重否定消去）：** <span class="course-math" data-tex="\displaystyle \dfrac{(\neg(\neg \alpha))}{\alpha}" data-display="false"><code>\displaystyle \dfrac{(\neg(\neg \alpha))}{\alpha}</code></span>

- **Implication Elimination（蕴含消去）：** <span class="course-math" data-tex="\displaystyle \dfrac{(\alpha \to \beta)}{(\neg \alpha \lor \beta)}" data-display="false"><code>\displaystyle \dfrac{(\alpha \to \beta)}{(\neg \alpha \lor \beta)}</code></span>

- **Biconditional Elimination（双条件消去）：** <span class="course-math" data-tex="\displaystyle \dfrac{(\alpha \leftrightarrow \beta)}{((\alpha \to \beta) \land (\beta \to \alpha))}" data-display="false"><code>\displaystyle \dfrac{(\alpha \leftrightarrow \beta)}{((\alpha \to \beta) \land (\beta \to \alpha))}</code></span>

- **De Morgan's law（德摩根律）：**
  - <span class="course-math" data-tex="\displaystyle \dfrac{\neg(\alpha \land \beta)}{(\neg \alpha \lor \neg \beta)}" data-display="false"><code>\displaystyle \dfrac{\neg(\alpha \land \beta)}{(\neg \alpha \lor \neg \beta)}</code></span>
  - <span class="course-math" data-tex="\displaystyle \dfrac{\neg(\alpha \lor \beta)}{(\neg \alpha \land \neg \beta)}" data-display="false"><code>\displaystyle \dfrac{\neg(\alpha \lor \beta)}{(\neg \alpha \land \neg \beta)}</code></span>

- **Distributive Property（分配律）：**
  - <span class="course-math" data-tex="\displaystyle \dfrac{(\alpha \land (\beta \lor \gamma))}{((\alpha \land \beta) \lor (\alpha \land \gamma))}" data-display="false"><code>\displaystyle \dfrac{(\alpha \land (\beta \lor \gamma))}{((\alpha \land \beta) \lor (\alpha \land \gamma))}</code></span>
  - <span class="course-math" data-tex="\displaystyle \dfrac{(\alpha \lor (\beta \land \gamma))}{((\alpha \lor \beta) \land (\alpha \lor \gamma))}" data-display="false"><code>\displaystyle \dfrac{(\alpha \lor (\beta \land \gamma))}{((\alpha \lor \beta) \land (\alpha \lor \gamma))}</code></span>


> <span class="course-math" data-tex="()" data-display="false"><code>()</code></span> is equivalent to *false*: <span class="course-math course-math-display" data-tex="\dfrac{\begin{array}{c}&#10;P \\&#10;\neg P&#10;\end{array}}{()}" data-display="true"><code>\dfrac{\begin{array}{c}&#10;P \\&#10;\neg P&#10;\end{array}}{()}</code></span>


### Inference by Resolution（归结推理）
{: #section-4 }


To determine if KB entails <span class="course-math" data-tex="\alpha" data-display="false"><code>\alpha</code></span>, we check if <span class="course-math" data-tex="(\text{KB}\land \neg\alpha)" data-display="false"><code>(\text{KB}\land \neg\alpha)</code></span> is a contradiction.
1. Convert <span class="course-math" data-tex="(\text{KB}\land \neg\alpha)" data-display="false"><code>(\text{KB}\land \neg\alpha)</code></span>  to Conjunctive Normal Form.
2. Keep checking to see if we can use resolution（归结） to produce a new clause.
3. If we ever produce the empty clause（空子句）, i.e., there is a contradiction, then <span class="course-math" data-tex="\text{KB}\vDash \alpha" data-display="false"><code>\text{KB}\vDash \alpha</code></span>.
4. If contradiction is not achieved and no more clauses can be inferred, there is no entailment.
