<span class="course-math" data-tex="\mathbf{x}, \mathbf{y} \in \mathbb{R}^{n}" data-display="false"><code>\mathbf{x}, \mathbf{y} \in \mathbb{R}^{n}</code></span> 正交（Orthogonal）定义为  <span class="course-math" data-tex="\mathbf{x}^{\top}\mathbf{y}=0" data-display="false"><code>\mathbf{x}^{\top}\mathbf{y}=0</code></span>。
<span class="course-math" data-tex="\mathbf{x}\in \mathbb{R}^n" data-display="false"><code>\mathbf{x}\in \mathbb{R}^n</code></span> 的长度（Length）定义为 <span class="course-math" data-tex="\lVert \mathbf{x}\rVert  = \sqrt{ \mathbf{x}^{\top}\mathbf{x} }" data-display="false"><code>\lVert \mathbf{x}\rVert  = \sqrt{ \mathbf{x}^{\top}\mathbf{x} }</code></span>。
<span class="course-math" data-tex="\mathbf{x},\mathbf{y}\in \mathbb{R}^n" data-display="false"><code>\mathbf{x},\mathbf{y}\in \mathbb{R}^n</code></span> 之间的角度定义为 <span class="course-math" data-tex="\cos\theta= \frac{\mathbf{x}^{\top}\mathbf{y}}{\lVert \mathbf{x} \rVert\lVert \mathbf{y} \rVert}" data-display="false"><code>\cos\theta= \frac{\mathbf{x}^{\top}\mathbf{y}}{\lVert \mathbf{x} \rVert\lVert \mathbf{y} \rVert}</code></span>。

**柯西-施瓦茨不等式（Cauchy-Schwarz）：** 对于任意两个内积空间中的向量 <span class="course-math" data-tex="\mathbf{x},\mathbf{y}" data-display="false"><code>\mathbf{x},\mathbf{y}</code></span>，有：
<span class="course-math course-math-display" data-tex="\lvert \mathbf{x}\cdot \mathbf{y}\rvert ^{2}\leq \lvert \mathbf{x} \cdot \mathbf{x} \rvert \lvert \mathbf{y}\cdot \mathbf{y} \rvert" data-display="true"><code>\lvert \mathbf{x}\cdot \mathbf{y}\rvert ^{2}\leq \lvert \mathbf{x} \cdot \mathbf{x} \rvert \lvert \mathbf{y}\cdot \mathbf{y} \rvert</code></span>
这和角度的定义相统一，因为 <span class="course-math" data-tex="\lvert \cos\theta\rvert \leq 1" data-display="false"><code>\lvert \cos\theta\rvert \leq 1</code></span> 。

定理：若一组向量相互正交且它们不是零向量，则它们是线性无关的。
- 证明：对于方程 <span class="course-math" data-tex="c_{1}\mathbf{v}_{1}+c_{2}\mathbf{v}_{2}+\dots+c_{n}\mathbf{v}_{n}=0" data-display="false"><code>c_{1}\mathbf{v}_{1}+c_{2}\mathbf{v}_{2}+\dots+c_{n}\mathbf{v}_{n}=0</code></span>，将它点乘 <span class="course-math" data-tex="\mathbf{v}_{1}" data-display="false"><code>\mathbf{v}_{1}</code></span> 得 <span class="course-math" data-tex="\mathbf{v}_{1}^{\top}(c_{1}\mathbf{v}_{1}+c_{2}\mathbf{v}_{2}+\dots+c_{n}\mathbf{v}_{n})=0" data-display="false"><code>\mathbf{v}_{1}^{\top}(c_{1}\mathbf{v}_{1}+c_{2}\mathbf{v}_{2}+\dots+c_{n}\mathbf{v}_{n})=0</code></span>，也就是说 <span class="course-math" data-tex="\mathbf{v}_{1}^{\top}c_{1}\mathbf{v}_{1}=c_{1}\lVert \mathbf{v}_{1} \rVert^{2}=0" data-display="false"><code>\mathbf{v}_{1}^{\top}c_{1}\mathbf{v}_{1}=c_{1}\lVert \mathbf{v}_{1} \rVert^{2}=0</code></span>。由于 <span class="course-math" data-tex="\lVert \mathbf{v}_{1} \rVert\neq 0" data-display="false"><code>\lVert \mathbf{v}_{1} \rVert\neq 0</code></span>，那么 <span class="course-math" data-tex="c_{1}=0" data-display="false"><code>c_{1}=0</code></span>。类似的 <span class="course-math" data-tex="c_{i}" data-display="false"><code>c_{i}</code></span> 都为 <span class="course-math" data-tex="0" data-display="false"><code>0</code></span>。

两个子空间 <span class="course-math" data-tex="V,\mathbf{W}" data-display="false"><code>V,\mathbf{W}</code></span> 彼此正交定义为 <span class="course-math" data-tex="\forall \mathbf{v}\in V, \mathbf{w}\in \mathbf{W}" data-display="false"><code>\forall \mathbf{v}\in V, \mathbf{w}\in \mathbf{W}</code></span>，有 <span class="course-math" data-tex="\mathbf{v}^{\top}\mathbf{w}=0" data-display="false"><code>\mathbf{v}^{\top}\mathbf{w}=0</code></span>。记作 <span class="course-math" data-tex="V \perp \mathbf{W}" data-display="false"><code>V \perp \mathbf{W}</code></span>。

<span class="course-math" data-tex="C(\mathbf{A})\perp N(\mathbf{A}^{\top})" data-display="false"><code>C(\mathbf{A})\perp N(\mathbf{A}^{\top})</code></span>
- 证明：<span class="course-math" data-tex="\mathbf{b} \in C(\mathbf{A}) \implies \exists \mathbf{x},\text{s.t. }\mathbf{A}\mathbf{x}=\mathbf{b}" data-display="false"><code>\mathbf{b} \in C(\mathbf{A}) \implies \exists \mathbf{x},\text{s.t. }\mathbf{A}\mathbf{x}=\mathbf{b}</code></span>；<span class="course-math" data-tex="\mathbf{y}\in N(\mathbf{A}^{\top})\implies \mathbf{y}^{\top}\mathbf{A}=0" data-display="false"><code>\mathbf{y}\in N(\mathbf{A}^{\top})\implies \mathbf{y}^{\top}\mathbf{A}=0</code></span>。从而 <span class="course-math" data-tex="\mathbf{y}^{\top}\mathbf{b}=\mathbf{y}^{\top}(\mathbf{A}\mathbf{x})=(\mathbf{y}^{\top}\mathbf{A})\mathbf{x}=0" data-display="false"><code>\mathbf{y}^{\top}\mathbf{b}=\mathbf{y}^{\top}(\mathbf{A}\mathbf{x})=(\mathbf{y}^{\top}\mathbf{A})\mathbf{x}=0</code></span>。从而 <span class="course-math" data-tex="\mathbf{y}^{\top}\perp \mathbf{b}" data-display="false"><code>\mathbf{y}^{\top}\perp \mathbf{b}</code></span>。

<span class="course-math" data-tex="C(\mathbf{A}^{\top})\perp N(\mathbf{A})" data-display="false"><code>C(\mathbf{A}^{\top})\perp N(\mathbf{A})</code></span>
- 证明：<span class="course-math" data-tex="\mathbf{x}\in N(\mathbf{A})\implies \mathbf{A}\mathbf{x}=0\implies \mathbf{x}^{\top}\mathbf{A}^{\top}=0" data-display="false"><code>\mathbf{x}\in N(\mathbf{A})\implies \mathbf{A}\mathbf{x}=0\implies \mathbf{x}^{\top}\mathbf{A}^{\top}=0</code></span>，故 <span class="course-math" data-tex="\mathbf{x}\perp \mathbf{A}^{\top}" data-display="false"><code>\mathbf{x}\perp \mathbf{A}^{\top}</code></span>。

<span class="course-math" data-tex="V\subseteq \mathbb{R}^n" data-display="false"><code>V\subseteq \mathbb{R}^n</code></span> 的垂直补（Orthogonal Complement）定义为所有满足 <span class="course-math" data-tex="\mathbf{v}\perp V" data-display="false"><code>\mathbf{v}\perp V</code></span> 的向量 <span class="course-math" data-tex="\mathbf{v}" data-display="false"><code>\mathbf{v}</code></span> 组成的集合，记作 <span class="course-math" data-tex="V^{\perp}" data-display="false"><code>V^{\perp}</code></span>。一个空间和其垂直补的维数之和为 <span class="course-math" data-tex="n" data-display="false"><code>n</code></span>。

可以证明 <span class="course-math" data-tex="C(\mathbf{A})^{\perp}=N(\mathbf{A}^{\top}), C(\mathbf{A}^{\top})^{\perp}= N(\mathbf{A})" data-display="false"><code>C(\mathbf{A})^{\perp}=N(\mathbf{A}^{\top}), C(\mathbf{A}^{\top})^{\perp}= N(\mathbf{A})</code></span>。
- <span class="course-math" data-tex="\mathbf{A}\mathbf{x}=\mathbf{b}" data-display="false"><code>\mathbf{A}\mathbf{x}=\mathbf{b}</code></span> 相容的一个等价条件：<span class="course-math" data-tex="\mathbf{y}^{\top}\mathbf{b}=0 , \forall \mathbf{y}\in N(\mathbf{A}^{\top})" data-display="false"><code>\mathbf{y}^{\top}\mathbf{b}=0 , \forall \mathbf{y}\in N(\mathbf{A}^{\top})</code></span>。

<span class="course-math" data-tex="\mathbf{A}" data-display="false"><code>\mathbf{A}</code></span> 表示的线性变换把 <span class="course-math" data-tex="C(\mathbf{A}^{\top})" data-display="false"><code>C(\mathbf{A}^{\top})</code></span> 映射到 <span class="course-math" data-tex="C(\mathbf{A})" data-display="false"><code>C(\mathbf{A})</code></span> 中，把 <span class="course-math" data-tex="N(\mathbf{A})" data-display="false"><code>N(\mathbf{A})</code></span> 映射到 <span class="course-math" data-tex="0" data-display="false"><code>0</code></span>。对于任何一个 <span class="course-math" data-tex="n" data-display="false"><code>n</code></span> 维向量 <span class="course-math" data-tex="\mathbf{x}" data-display="false"><code>\mathbf{x}</code></span>，它可以写成 <span class="course-math" data-tex="\mathbf{x}=\mathbf{x}_{r}+\mathbf{x}_{n}" data-display="false"><code>\mathbf{x}=\mathbf{x}_{r}+\mathbf{x}_{n}</code></span>，而 <span class="course-math" data-tex="\mathbf{A}\mathbf{x}=\mathbf{A}(\mathbf{x}_{r}+\mathbf{x}_{n})=\mathbf{A}\mathbf{x}_{r}" data-display="false"><code>\mathbf{A}\mathbf{x}=\mathbf{A}(\mathbf{x}_{r}+\mathbf{x}_{n})=\mathbf{A}\mathbf{x}_{r}</code></span>。这里 <span class="course-math" data-tex="\mathbf{x}_{r}" data-display="false"><code>\mathbf{x}_{r}</code></span> 是行空间中的一个向量，而 <span class="course-math" data-tex="\mathbf{A}\mathbf{x}_{r}" data-display="false"><code>\mathbf{A}\mathbf{x}_{r}</code></span> 是列空间中的一个向量。所以从几何上看，它把自己的行空间映射到列空间。


## 投影与最小平方解
{: #section-1 }


<span class="course-math" data-tex="\mathbf{b}" data-display="false"><code>\mathbf{b}</code></span> 在非零向量 <span class="course-math" data-tex="\mathbf{a}" data-display="false"><code>\mathbf{a}</code></span> 上的投影（Projection）：<span class="course-math" data-tex="\mathbf{p}= \lVert \mathbf{b} \rVert\cos\theta  \frac{\mathbf{a}}{\lVert \mathbf{a} \rVert}=\frac{\mathbf{a}^{\top}\mathbf{b}}{\lVert \mathbf{a} \rVert^{2}}\mathbf{a}" data-display="false"><code>\mathbf{p}= \lVert \mathbf{b} \rVert\cos\theta  \frac{\mathbf{a}}{\lVert \mathbf{a} \rVert}=\frac{\mathbf{a}^{\top}\mathbf{b}}{\lVert \mathbf{a} \rVert^{2}}\mathbf{a}</code></span>。
投影的矩阵表示： <span class="course-math" data-tex="\mathbf{T}:\mathbb{R}^n\to \mathbb{R}^n, \mathbf{b} \mapsto \frac{\mathbf{a}^{\top}\mathbf{b}}{\lVert \mathbf{a} \rVert^{2}}\mathbf{a}" data-display="false"><code>\mathbf{T}:\mathbb{R}^n\to \mathbb{R}^n, \mathbf{b} \mapsto \frac{\mathbf{a}^{\top}\mathbf{b}}{\lVert \mathbf{a} \rVert^{2}}\mathbf{a}</code></span>。所以矩阵表示就是 <span class="course-math" data-tex="\frac{\mathbf{a}\mathbf{a}^{\top}}{\mathbf{a}^{\top}\mathbf{a}}" data-display="false"><code>\frac{\mathbf{a}\mathbf{a}^{\top}}{\mathbf{a}^{\top}\mathbf{a}}</code></span>。

应用：**最小平方解（Least Square Solutions）**，求平方和 <span class="course-math" data-tex="\sum_{i=1}^m(a_{i1}x_{1}+a_{i2}x_{2}+\dots+a_{in}x_{n}-b_{i})^{2}" data-display="false"><code>\sum_{i=1}^m(a_{i1}x_{1}+a_{i2}x_{2}+\dots+a_{in}x_{n}-b_{i})^{2}</code></span> 的最小值，其中 <span class="course-math" data-tex="a_{ij}, b_{i}" data-display="false"><code>a_{ij}, b_{i}</code></span> 为常数。
- 把问题转换为求 <span class="course-math" data-tex="\lVert \mathbf{A}\mathbf{x}-\mathbf{b} \rVert^{2}" data-display="false"><code>\lVert \mathbf{A}\mathbf{x}-\mathbf{b} \rVert^{2}</code></span> 的最小值。<span class="course-math" data-tex="\mathbf{A}" data-display="false"><code>\mathbf{A}</code></span> 将 <span class="course-math" data-tex="\mathbf{x}" data-display="false"><code>\mathbf{x}</code></span> 映射到 <span class="course-math" data-tex="C(\mathbf{A})" data-display="false"><code>C(\mathbf{A})</code></span> 中。在平面 <span class="course-math" data-tex="C(\mathbf{A})" data-display="false"><code>C(\mathbf{A})</code></span> 中的向量 <span class="course-math" data-tex="\mathbf{A}\mathbf{x}" data-display="false"><code>\mathbf{A}\mathbf{x}</code></span> 与任意向量 <span class="course-math" data-tex="\mathbf{b}" data-display="false"><code>\mathbf{b}</code></span> 终点连线的长度最小，需要这个连线与 <span class="course-math" data-tex="C(\mathbf{A})" data-display="false"><code>C(\mathbf{A})</code></span> 垂直，所以 <span class="course-math" data-tex="\mathbf{b}-\mathbf{A}\hat{\mathbf{x}} \in C(\mathbf{A})^{\perp}=N(\mathbf{A}^{\top})" data-display="false"><code>\mathbf{b}-\mathbf{A}\hat{\mathbf{x}} \in C(\mathbf{A})^{\perp}=N(\mathbf{A}^{\top})</code></span>。那么 <span class="course-math" data-tex="\mathbf{A}^{\top}(\mathbf{b}-\mathbf{A}\hat{\mathbf{x}})=0" data-display="false"><code>\mathbf{A}^{\top}(\mathbf{b}-\mathbf{A}\hat{\mathbf{x}})=0</code></span>。
- **只需解方程 <span class="course-math" data-tex="(\mathbf{A}^{\top} \mathbf{A})\hat{\mathbf{x}}=\mathbf{A}^{\top} \mathbf{b}" data-display="false"><code>(\mathbf{A}^{\top} \mathbf{A})\hat{\mathbf{x}}=\mathbf{A}^{\top} \mathbf{b}</code></span>。**
- 为什么这个方程组有解？从几何角度可以理解。
- 也可以通过证明 <span class="course-math" data-tex="\operatorname{rank}(\mathbf{A}^{\top}\mathbf{A})=\operatorname{rank}(\begin{bmatrix}\mathbf{A}^{\top}\mathbf{A} &amp;\mathbf{A}^{\top}\mathbf{b}\end{bmatrix})" data-display="false"><code>\operatorname{rank}(\mathbf{A}^{\top}\mathbf{A})=\operatorname{rank}(\begin{bmatrix}\mathbf{A}^{\top}\mathbf{A} &amp;\mathbf{A}^{\top}\mathbf{b}\end{bmatrix})</code></span>。
  - 显然 <span class="course-math" data-tex="\operatorname{rank}(\mathbf{A}^{\top}\mathbf{A})\leq\operatorname{rank}(\begin{bmatrix}\mathbf{A}^{\top}\mathbf{A} &amp;\mathbf{A}^{\top}\mathbf{b}\end{bmatrix})" data-display="false"><code>\operatorname{rank}(\mathbf{A}^{\top}\mathbf{A})\leq\operatorname{rank}(\begin{bmatrix}\mathbf{A}^{\top}\mathbf{A} &amp;\mathbf{A}^{\top}\mathbf{b}\end{bmatrix})</code></span>。
  - 另有 <span class="course-math" data-tex="\operatorname{rank}(\mathbf{A}^{\top}\mathbf{A})=\operatorname{rank}(\mathbf{A}^{\top})\geq\operatorname{rank}(\mathbf{A}^{\top} \begin{bmatrix}\mathbf{A} &amp; \mathbf{b}\end{bmatrix})=\operatorname{rank}(\begin{bmatrix}\mathbf{A}^{\top}\mathbf{A} &amp; \mathbf{A}^{\top}\mathbf{b}\end{bmatrix})" data-display="false"><code>\operatorname{rank}(\mathbf{A}^{\top}\mathbf{A})=\operatorname{rank}(\mathbf{A}^{\top})\geq\operatorname{rank}(\mathbf{A}^{\top} \begin{bmatrix}\mathbf{A} &amp; \mathbf{b}\end{bmatrix})=\operatorname{rank}(\begin{bmatrix}\mathbf{A}^{\top}\mathbf{A} &amp; \mathbf{A}^{\top}\mathbf{b}\end{bmatrix})</code></span>。
- 若 <span class="course-math" data-tex="\mathbf{A}^{\top} \mathbf{A}" data-display="false"><code>\mathbf{A}^{\top} \mathbf{A}</code></span> 可逆，则 <span class="course-math" data-tex="\hat{\mathbf{x}}=(\mathbf{A}^{\top}\mathbf{A})^{-1}\mathbf{A}^{\top} \mathbf{b}" data-display="false"><code>\hat{\mathbf{x}}=(\mathbf{A}^{\top}\mathbf{A})^{-1}\mathbf{A}^{\top} \mathbf{b}</code></span> 。也就是，<span class="course-math" data-tex="\mathbf{A}" data-display="false"><code>\mathbf{A}</code></span> 的最优左逆左乘 <span class="course-math" data-tex="\mathbf{b}" data-display="false"><code>\mathbf{b}</code></span>。
- 若 <span class="course-math" data-tex="\mathbf{A}" data-display="false"><code>\mathbf{A}</code></span> 可逆，则可以进一步得到 <span class="course-math" data-tex="\hat{\mathbf{x}}=\mathbf{A}^{-1}\mathbf{b}" data-display="false"><code>\hat{\mathbf{x}}=\mathbf{A}^{-1}\mathbf{b}</code></span>。

对于 <span class="course-math" data-tex="n=2" data-display="false"><code>n=2</code></span> 的情况就是用最小二乘法求线性回归直线。
- 设这个回归直线为  <span class="course-math" data-tex="b=C+Dt" data-display="false"><code>b=C+Dt</code></span>。则要使得残差平方和 <span class="course-math" data-tex="\sum_{i=1}^m(C+Dt_{i}-b_{i})^{2}" data-display="false"><code>\sum_{i=1}^m(C+Dt_{i}-b_{i})^{2}</code></span> 最小。
- 这里

  <span class="course-math course-math-display" data-tex="\mathbf{A}=\begin{bmatrix}1 &amp; t_{1} \\ 1  &amp; t_{2} \\ \dots &amp; \dots \\ 1 &amp; t_{m}\end{bmatrix}" data-display="true"><code>\mathbf{A}=\begin{bmatrix}1 &amp; t_{1} \\ 1  &amp; t_{2} \\ \dots &amp; \dots \\ 1 &amp; t_{m}\end{bmatrix}</code></span>

  ，

  <span class="course-math course-math-display" data-tex="\mathbf{b}=\begin{bmatrix}b_{1} \\ b_{2} \\ \dots \\ b_{m}\end{bmatrix}" data-display="true"><code>\mathbf{b}=\begin{bmatrix}b_{1} \\ b_{2} \\ \dots \\ b_{m}\end{bmatrix}</code></span>

  。
- 则只需解方程

  <span class="course-math course-math-display" data-tex="\mathbf{A}^{\top}\mathbf{A}\begin{bmatrix}C \\ D\end{bmatrix}=\mathbf{A}^{\top}\mathbf{b}" data-display="true"><code>\mathbf{A}^{\top}\mathbf{A}\begin{bmatrix}C \\ D\end{bmatrix}=\mathbf{A}^{\top}\mathbf{b}</code></span>

   即可求出直线的系数。
- 为了方便计算，可以让 <span class="course-math" data-tex="b=C_{1}+D_{1}(t-\bar{t})" data-display="false"><code>b=C_{1}+D_{1}(t-\bar{t})</code></span>，这里原直线的参数 <span class="course-math" data-tex="C=C_{1}-D_{1}\bar t, D=D_{1}" data-display="false"><code>C=C_{1}-D_{1}\bar t, D=D_{1}</code></span>。那么

  <span class="course-math course-math-display" data-tex="\mathbf{A}=\begin{bmatrix}1 &amp; t_{1}-\bar{t} \\ 1 &amp; t_{2}-\bar{t} \\ \dots &amp; \dots \\ 1 &amp; t_{m}-\bar{t}\end{bmatrix}" data-display="true"><code>\mathbf{A}=\begin{bmatrix}1 &amp; t_{1}-\bar{t} \\ 1 &amp; t_{2}-\bar{t} \\ \dots &amp; \dots \\ 1 &amp; t_{m}-\bar{t}\end{bmatrix}</code></span>

  ，则 <span class="course-math" data-tex="\mathbf{A}=\begin{bmatrix}\mathbf{v}_{1} &amp; \mathbf{v}_{2}\end{bmatrix}" data-display="false"><code>\mathbf{A}=\begin{bmatrix}\mathbf{v}_{1} &amp; \mathbf{v}_{2}\end{bmatrix}</code></span> 的两列是正交的。那么 <span class="course-math" data-tex="\hat{C}_1=\frac{\mathbf{v}_{1}^{\top}b}{\mathbf{v}_{1}^{\top}\mathbf{v}_{1}},\hat{D}_1=\frac{\mathbf{v}_{2}^{\top}b}{\mathbf{v}_{2}^{\top}\mathbf{v}_{2}}" data-display="false"><code>\hat{C}_1=\frac{\mathbf{v}_{1}^{\top}b}{\mathbf{v}_{1}^{\top}\mathbf{v}_{1}},\hat{D}_1=\frac{\mathbf{v}_{2}^{\top}b}{\mathbf{v}_{2}^{\top}\mathbf{v}_{2}}</code></span>。

考虑这个几何问题，选取 <span class="course-math" data-tex="C(\mathbf{A})" data-display="false"><code>C(\mathbf{A})</code></span> 的一组基作为 <span class="course-math" data-tex="\mathbf{A}" data-display="false"><code>\mathbf{A}</code></span> 的列（列满秩）。
- 由于 <span class="course-math" data-tex="\mathbf{A}\hat{\mathbf{x}}" data-display="false"><code>\mathbf{A}\hat{\mathbf{x}}</code></span> 为 <span class="course-math" data-tex="C(\mathbf{A})" data-display="false"><code>C(\mathbf{A})</code></span> 上使得其终点与 <span class="course-math" data-tex="\mathbf{b}" data-display="false"><code>\mathbf{b}</code></span> 终点连线垂直于 <span class="course-math" data-tex="C(\mathbf{A})" data-display="false"><code>C(\mathbf{A})</code></span> 的向量，<span class="course-math" data-tex="\mathbf{b}" data-display="false"><code>\mathbf{b}</code></span> 在 <span class="course-math" data-tex="C(\mathbf{A})" data-display="false"><code>C(\mathbf{A})</code></span> 上的投影即为 <span class="course-math" data-tex="\mathbf{p}=\mathbf{A}\hat{\mathbf{x}}=\mathbf{A}(\mathbf{A}^{\top}\mathbf{A})^{-1}\mathbf{A}^{\top}\mathbf{b}" data-display="false"><code>\mathbf{p}=\mathbf{A}\hat{\mathbf{x}}=\mathbf{A}(\mathbf{A}^{\top}\mathbf{A})^{-1}\mathbf{A}^{\top}\mathbf{b}</code></span>。
- 那么投影到 <span class="course-math" data-tex="C(\mathbf{A})" data-display="false"><code>C(\mathbf{A})</code></span> 的线性变换的矩阵表示为 <span class="course-math" data-tex="\mathbf{P}=\mathbf{A}(\mathbf{A}^{\top}\mathbf{A})^{-1} \mathbf{A}^{\top}" data-display="false"><code>\mathbf{P}=\mathbf{A}(\mathbf{A}^{\top}\mathbf{A})^{-1} \mathbf{A}^{\top}</code></span>。
- 这里 <span class="course-math" data-tex="\mathbf{P}" data-display="false"><code>\mathbf{P}</code></span> 有些性质。比如 <span class="course-math" data-tex="\mathbf{P}^{2}=\mathbf{P}" data-display="false"><code>\mathbf{P}^{2}=\mathbf{P}</code></span>, <span class="course-math" data-tex="\mathbf{P}^{\top}=\mathbf{P}" data-display="false"><code>\mathbf{P}^{\top}=\mathbf{P}</code></span>。


**定义投影矩阵（Projection Matrix）**：满足 <span class="course-math" data-tex="\mathbf{P}^{2}=\mathbf{P}" data-display="false"><code>\mathbf{P}^{2}=\mathbf{P}</code></span> 且 <span class="course-math" data-tex="\mathbf{P}^{\top}=\mathbf{P}" data-display="false"><code>\mathbf{P}^{\top}=\mathbf{P}</code></span> 的矩阵。
- 任何投影矩阵都来自于投影到某个列空间 <span class="course-math" data-tex="C(\mathbf{A})" data-display="false"><code>C(\mathbf{A})</code></span> 的投影。
- 推论：容易验证 <span class="course-math" data-tex="\mathbf{Q}=\mathbf{I}-\mathbf{P}" data-display="false"><code>\mathbf{Q}=\mathbf{I}-\mathbf{P}</code></span> 也是投影矩阵。若 <span class="course-math" data-tex="\mathbf{P}=\mathbf{A}(\mathbf{A}^{\top}\mathbf{A})^{-1}\mathbf{A}^{\top}" data-display="false"><code>\mathbf{P}=\mathbf{A}(\mathbf{A}^{\top}\mathbf{A})^{-1}\mathbf{A}^{\top}</code></span>，则 <span class="course-math" data-tex="\mathbf{Q}" data-display="false"><code>\mathbf{Q}</code></span> 是投影到 <span class="course-math" data-tex="C(\mathbf{A})^{\perp}=N(\mathbf{A}^{\top})" data-display="false"><code>C(\mathbf{A})^{\perp}=N(\mathbf{A}^{\top})</code></span> 的投影矩阵。这是因为，<span class="course-math" data-tex="\mathbf{x}" data-display="false"><code>\mathbf{x}</code></span> 可以正交分解为 <span class="course-math" data-tex="\mathbf{P}\mathbf{x}+(\mathbf{I}-\mathbf{P})\mathbf{x}" data-display="false"><code>\mathbf{P}\mathbf{x}+(\mathbf{I}-\mathbf{P})\mathbf{x}</code></span>。
- 例如要求投影到平面 <span class="course-math" data-tex="x+y+z=0" data-display="false"><code>x+y+z=0</code></span> 的投影矩阵，可以先求投影到其法向量

  <span class="course-math course-math-display" data-tex="\mathbf{n}=\begin{bmatrix}1 \\ 1 \\ 1\end{bmatrix}" data-display="true"><code>\mathbf{n}=\begin{bmatrix}1 \\ 1 \\ 1\end{bmatrix}</code></span>

   上的投影矩阵 <span class="course-math" data-tex="\frac{\mathbf{n}\mathbf{n}^{\top}}{\mathbf{n}^{\top}\mathbf{n}}" data-display="false"><code>\frac{\mathbf{n}\mathbf{n}^{\top}}{\mathbf{n}^{\top}\mathbf{n}}</code></span>，再用恒等矩阵减去它。
- 求高维投影矩阵，不如去找它正交补的投影矩阵，再用恒等矩阵减去它就好了。


加权最小平方解（Weighted least-square solution）：求平方和 <span class="course-math" data-tex="\sum_{i=1}^mw_{i}^{2}(a_{i1}x_{1}+a_{i2}x_{2}+\dots+a_{in}x_{n}-b_{i})^{2}" data-display="false"><code>\sum_{i=1}^mw_{i}^{2}(a_{i1}x_{1}+a_{i2}x_{2}+\dots+a_{in}x_{n}-b_{i})^{2}</code></span> 的最小值，其中 <span class="course-math" data-tex="a_{ij}, b_{i}" data-display="false"><code>a_{ij}, b_{i}</code></span> 为常数。
- 只需要把 <span class="course-math" data-tex="w_{i}" data-display="false"><code>w_{i}</code></span> 放到平方里面去即可。
- 构造 <span class="course-math" data-tex="\mathbf{W}=\operatorname{diag}(w_1,\dots,w_m)" data-display="false"><code>\mathbf{W}=\operatorname{diag}(w_1,\dots,w_m)</code></span>，则转换为求 <span class="course-math" data-tex="\lVert \mathbf{W}\mathbf{A}\hat{\mathbf{x}_{w}}-\mathbf{W}\mathbf{b} \rVert^{2}" data-display="false"><code>\lVert \mathbf{W}\mathbf{A}\hat{\mathbf{x}_{w}}-\mathbf{W}\mathbf{b} \rVert^{2}</code></span> 的最小值。
- 也就是 <span class="course-math" data-tex="(\mathbf{W}\mathbf{A})^{\top}(\mathbf{W}\mathbf{A})\hat{\mathbf{x}_{w}}=(\mathbf{W}\mathbf{A})^{\top}(\mathbf{W}\mathbf{b})" data-display="false"><code>(\mathbf{W}\mathbf{A})^{\top}(\mathbf{W}\mathbf{A})\hat{\mathbf{x}_{w}}=(\mathbf{W}\mathbf{A})^{\top}(\mathbf{W}\mathbf{b})</code></span>。
- 也就是 <span class="course-math" data-tex="\mathbf{A}^{\top}(\mathbf{W}^{\top}\mathbf{W})\mathbf{A}\hat{\mathbf{x}_{w}}=\mathbf{A}^{\top}(\mathbf{W}^{\top}\mathbf{W})\mathbf{b}" data-display="false"><code>\mathbf{A}^{\top}(\mathbf{W}^{\top}\mathbf{W})\mathbf{A}\hat{\mathbf{x}_{w}}=\mathbf{A}^{\top}(\mathbf{W}^{\top}\mathbf{W})\mathbf{b}</code></span>。


## 规范正交基与正交矩阵
{: #section-2 }


规定 <span class="course-math" data-tex="\mathbf{q}_{1},\mathbf{q}_{2},\dots,\mathbf{q}_{s}" data-display="false"><code>\mathbf{q}_{1},\mathbf{q}_{2},\dots,\mathbf{q}_{s}</code></span> 为一组向量，且满足：
  <span class="course-math course-math-display" data-tex="\mathbf{q}_{i}^{\top}\mathbf{q}_{j}=\begin{cases}&#10;1 &amp; i=j \\&#10;0 &amp; i\neq j&#10;\end{cases}" data-display="true"><code>\mathbf{q}_{i}^{\top}\mathbf{q}_{j}=\begin{cases}&#10;1 &amp; i=j \\&#10;0 &amp; i\neq j&#10;\end{cases}</code></span>
则称它们是规范正交（Orthonormal）的。
若 <span class="course-math" data-tex="\mathbf{q}_{1}, \mathbf{q}_{2},\dots,\mathbf{q}_{n}" data-display="false"><code>\mathbf{q}_{1}, \mathbf{q}_{2},\dots,\mathbf{q}_{n}</code></span> 是空间 <span class="course-math" data-tex="V" data-display="false"><code>V</code></span> 的一组基且它们规范正交，则称它们为规范正交基（Orthonormal Basis）。

正交矩阵（Orthogonal Matrix）：一个有着规范正交的列的**方矩阵**
<span class="course-math course-math-display" data-tex="\mathbf{Q}^{\top}\mathbf{Q}=\mathbf{I}" data-display="true"><code>\mathbf{Q}^{\top}\mathbf{Q}=\mathbf{I}</code></span>
例如，旋转矩阵，排列矩阵以及反射矩阵都是正交矩阵。
正交矩阵代表的变换会保持长度不变：
<span class="course-math course-math-display" data-tex="\lVert \mathbf{Q}\mathbf{x} \rVert=\lVert \mathbf{x} \rVert" data-display="true"><code>\lVert \mathbf{Q}\mathbf{x} \rVert=\lVert \mathbf{x} \rVert</code></span>
这是因为，<span class="course-math" data-tex="(\mathbf{Q}\mathbf{x})^{\top}(\mathbf{Q}\mathbf{x})=\mathbf{x}^{\top}\mathbf{Q}^{\top}\mathbf{Q}\mathbf{x}=\mathbf{x}^{\top}\mathbf{x}" data-display="false"><code>(\mathbf{Q}\mathbf{x})^{\top}(\mathbf{Q}\mathbf{x})=\mathbf{x}^{\top}\mathbf{Q}^{\top}\mathbf{Q}\mathbf{x}=\mathbf{x}^{\top}\mathbf{x}</code></span>。
更一般地，它会保持内积不变/夹角不变：
<span class="course-math course-math-display" data-tex="(\mathbf{Q}\mathbf{x})^{\top}(\mathbf{Q}\mathbf{y})=\mathbf{x}^{\top}\mathbf{y}" data-display="true"><code>(\mathbf{Q}\mathbf{x})^{\top}(\mathbf{Q}\mathbf{y})=\mathbf{x}^{\top}\mathbf{y}</code></span>

正交基/正交矩阵的好处：
- 坐标非常容易求出来。
<span class="course-math course-math-display" data-tex="\mathbf{b}=\sum x_{i}\mathbf{q}_{i}" data-display="true"><code>\mathbf{b}=\sum x_{i}\mathbf{q}_{i}</code></span>
<span class="course-math course-math-display" data-tex="\implies \mathbf{q}_{i}^{\top}\mathbf{b}=\mathbf{q}_{i}^{\top}\mathbf{q}_{i}x_{i}" data-display="true"><code>\implies \mathbf{q}_{i}^{\top}\mathbf{b}=\mathbf{q}_{i}^{\top}\mathbf{q}_{i}x_{i}</code></span>
<span class="course-math course-math-display" data-tex="\implies x_{i}=\mathbf{q}_{i}^{\top}\mathbf{b}" data-display="true"><code>\implies x_{i}=\mathbf{q}_{i}^{\top}\mathbf{b}</code></span>
- 逆非常容易求出来。
<span class="course-math course-math-display" data-tex="\mathbf{Q}=\begin{bmatrix}&#10;\mathbf{q}_{1} &amp; \mathbf{q}_{2} &amp; \dots &amp; \mathbf{q}_{n}&#10;\end{bmatrix}" data-display="true"><code>\mathbf{Q}=\begin{bmatrix}&#10;\mathbf{q}_{1} &amp; \mathbf{q}_{2} &amp; \dots &amp; \mathbf{q}_{n}&#10;\end{bmatrix}</code></span>
<span class="course-math course-math-display" data-tex="\implies \mathbf{Q}^{-1}=\mathbf{Q}^{\top}" data-display="true"><code>\implies \mathbf{Q}^{-1}=\mathbf{Q}^{\top}</code></span>
<span class="course-math course-math-display" data-tex="\mathbf{Q}\mathbf{x}=\mathbf{b}\implies \mathbf{x}=\mathbf{Q}^{\top}\mathbf{b}=\begin{bmatrix}&#10;\mathbf{q}_{1}^{\top}\mathbf{b} \\&#10;\dots \\&#10;\mathbf{q}_{n}^{\top}\mathbf{b}&#10;\end{bmatrix}" data-display="true"><code>\mathbf{Q}\mathbf{x}=\mathbf{b}\implies \mathbf{x}=\mathbf{Q}^{\top}\mathbf{b}=\begin{bmatrix}&#10;\mathbf{q}_{1}^{\top}\mathbf{b} \\&#10;\dots \\&#10;\mathbf{q}_{n}^{\top}\mathbf{b}&#10;\end{bmatrix}</code></span>
- 任意向量分解到基上都相当于投影上去。
<span class="course-math course-math-display" data-tex="\mathbf{b}=\sum (\mathbf{q}_{i}^{\top}\mathbf{b})\mathbf{q}_{i}" data-display="true"><code>\mathbf{b}=\sum (\mathbf{q}_{i}^{\top}\mathbf{b})\mathbf{q}_{i}</code></span>
- 长度很好求。
<span class="course-math course-math-display" data-tex="\lVert \mathbf{b} \rVert = \sqrt{ \sum (\mathbf{q}_{i}^{\top}\mathbf{b})^{2} }" data-display="true"><code>\lVert \mathbf{b} \rVert = \sqrt{ \sum (\mathbf{q}_{i}^{\top}\mathbf{b})^{2} }</code></span>

- <span class="course-math" data-tex="\mathbf{Q}^{\top}" data-display="false"><code>\mathbf{Q}^{\top}</code></span> 也是一个正交矩阵，也就是说行也是正交的
<span class="course-math course-math-display" data-tex="(\mathbf{Q}^{\top})^{\top}\mathbf{Q}^{\top}=(\mathbf{Q}\mathbf{Q}^{\top})^{\top}=\mathbf{I}" data-display="true"><code>(\mathbf{Q}^{\top})^{\top}\mathbf{Q}^{\top}=(\mathbf{Q}\mathbf{Q}^{\top})^{\top}=\mathbf{I}</code></span>
- 【*注意这里的 <span class="course-math" data-tex="\mathbf{Q}" data-display="false"><code>\mathbf{Q}</code></span> 代表不一定为方阵，但列正交的情况* 】若要求 <span class="course-math" data-tex="\mathbf{Q}\mathbf{x}=\mathbf{b}" data-display="false"><code>\mathbf{Q}\mathbf{x}=\mathbf{b}</code></span> 的最小平方解，则 <span class="course-math" data-tex="\hat{\mathbf{x}}=(\mathbf{Q}^{\top}\mathbf{Q})\mathbf{Q}^{\top}\mathbf{b}=\mathbf{Q}^{\top}\mathbf{b}" data-display="false"><code>\hat{\mathbf{x}}=(\mathbf{Q}^{\top}\mathbf{Q})\mathbf{Q}^{\top}\mathbf{b}=\mathbf{Q}^{\top}\mathbf{b}</code></span>，则投影 <span class="course-math" data-tex="\mathbf{p}=\mathbf{Q}\hat{\mathbf{x}}=\mathbf{Q}\mathbf{Q}^{\top}\mathbf{b}=\sum (\mathbf{q}_{i}^{\top}\mathbf{b})\mathbf{q}_{i}" data-display="false"><code>\mathbf{p}=\mathbf{Q}\hat{\mathbf{x}}=\mathbf{Q}\mathbf{Q}^{\top}\mathbf{b}=\sum (\mathbf{q}_{i}^{\top}\mathbf{b})\mathbf{q}_{i}</code></span>，也就是说，投影到 <span class="course-math" data-tex="C(\mathbf{Q})" data-display="false"><code>C(\mathbf{Q})</code></span> 相当于投影到 <span class="course-math" data-tex="\mathbf{Q}" data-display="false"><code>\mathbf{Q}</code></span> 的列向量上再相加。
- 投影到 <span class="course-math" data-tex="C(\mathbf{Q})" data-display="false"><code>C(\mathbf{Q})</code></span> 上的投影矩阵为 <span class="course-math" data-tex="\mathbf{P}=\mathbf{Q}(\mathbf{Q}^{\top}\mathbf{Q})^{-1}\mathbf{Q}^{\top}=\mathbf{Q}\mathbf{Q}^{\top}" data-display="false"><code>\mathbf{P}=\mathbf{Q}(\mathbf{Q}^{\top}\mathbf{Q})^{-1}\mathbf{Q}^{\top}=\mathbf{Q}\mathbf{Q}^{\top}</code></span>。


## Householder 变换
{: #section-3 }


Householder 变换：将某个向量 <span class="course-math" data-tex="\mathbf{x}" data-display="false"><code>\mathbf{x}</code></span> 关于某个 <span class="course-math" data-tex="n-1" data-display="false"><code>n-1</code></span> 维超平面  <span class="course-math" data-tex="V" data-display="false"><code>V</code></span>  做反射。假设平面的法向量为 <span class="course-math" data-tex="\mathbf{v}" data-display="false"><code>\mathbf{v}</code></span>，则变换的矩阵表示为
<span class="course-math course-math-display" data-tex="\mathbf{H}=\mathbf{I}_{n}-2 \frac{\mathbf{v}\mathbf{v}^{\top}}{\mathbf{v}^{\top}\mathbf{v}}" data-display="true"><code>\mathbf{H}=\mathbf{I}_{n}-2 \frac{\mathbf{v}\mathbf{v}^{\top}}{\mathbf{v}^{\top}\mathbf{v}}</code></span>
这是因为，<span class="course-math" data-tex="\mathbf{H}:\mathbb{R}^n \to \mathbb{R}^n, \mathbf{x}=\mathbf{x}_{\parallel}+\mathbf{x}_{\perp}\mapsto \mathbf{x}_{\parallel}-\mathbf{x}_{\perp}" data-display="false"><code>\mathbf{H}:\mathbb{R}^n \to \mathbb{R}^n, \mathbf{x}=\mathbf{x}_{\parallel}+\mathbf{x}_{\perp}\mapsto \mathbf{x}_{\parallel}-\mathbf{x}_{\perp}</code></span>，又有 <span class="course-math" data-tex="\mathbf{P}_{v}\mathbf{x}=\mathbf{x}_{\perp}" data-display="false"><code>\mathbf{P}_{v}\mathbf{x}=\mathbf{x}_{\perp}</code></span>，则 <span class="course-math" data-tex="\mathbf{H}\mathbf{x}=\mathbf{x}_{\parallel}-\mathbf{x}_{\perp}=\mathbf{x}-2\mathbf{x}_{\perp}=\mathbf{x}-2\mathbf{P}_{v}\mathbf{x}" data-display="false"><code>\mathbf{H}\mathbf{x}=\mathbf{x}_{\parallel}-\mathbf{x}_{\perp}=\mathbf{x}-2\mathbf{x}_{\perp}=\mathbf{x}-2\mathbf{P}_{v}\mathbf{x}</code></span>，进而 <span class="course-math" data-tex="\mathbf{H}=\mathbf{I}-2\mathbf{P}_{v}=\mathbf{I}-2 \frac{\mathbf{v}\mathbf{v}^{\top}}{\mathbf{v}^{\top}\mathbf{v}}" data-display="false"><code>\mathbf{H}=\mathbf{I}-2\mathbf{P}_{v}=\mathbf{I}-2 \frac{\mathbf{v}\mathbf{v}^{\top}}{\mathbf{v}^{\top}\mathbf{v}}</code></span>。
- 对合性：<span class="course-math" data-tex="\mathbf{H}^{2}=\mathbf{I}" data-display="false"><code>\mathbf{H}^{2}=\mathbf{I}</code></span>
- 正交性：<span class="course-math" data-tex="\mathbf{H}^{\top}\mathbf{H}=\mathbf{I}" data-display="false"><code>\mathbf{H}^{\top}\mathbf{H}=\mathbf{I}</code></span>
- 对称性：<span class="course-math" data-tex="\mathbf{H}=\mathbf{H}^{\top}" data-display="false"><code>\mathbf{H}=\mathbf{H}^{\top}</code></span>
Householder 变换的意义在于，作为一个反射变换，它可以将向量的某些元素置零而保持长度不变。
- 例题：要找某个对称矩阵 <span class="course-math" data-tex="\mathbf{A}" data-display="false"><code>\mathbf{A}</code></span> 使得 <span class="course-math" data-tex="\mathbf{A}^{2}=\mathbf{I}" data-display="false"><code>\mathbf{A}^{2}=\mathbf{I}</code></span> 且其第一列为某单位向量 <span class="course-math" data-tex="\mathbf{u}" data-display="false"><code>\mathbf{u}</code></span>。
- 若 <span class="course-math" data-tex="\mathbf{u}=\mathbf{e}_1" data-display="false"><code>\mathbf{u}=\mathbf{e}_1</code></span>，可取 <span class="course-math" data-tex="\mathbf{A}=\mathbf{I}" data-display="false"><code>\mathbf{A}=\mathbf{I}</code></span>；否则令 <span class="course-math" data-tex="\mathbf{A}" data-display="false"><code>\mathbf{A}</code></span> 为一个 Householder 矩阵，由题意得 <span class="course-math" data-tex="\mathbf{A}\mathbf{e}_{1}=\mathbf{u}" data-display="false"><code>\mathbf{A}\mathbf{e}_{1}=\mathbf{u}</code></span>，也就是说 <span class="course-math" data-tex="\mathbf{e}_{1}" data-display="false"><code>\mathbf{e}_{1}</code></span> 与 <span class="course-math" data-tex="\mathbf{u}" data-display="false"><code>\mathbf{u}</code></span> 关于 Householder 变换的超平面对称，那么可以取法向量 <span class="course-math" data-tex="\mathbf{v}=\mathbf{e}_{1}-\mathbf{u}" data-display="false"><code>\mathbf{v}=\mathbf{e}_{1}-\mathbf{u}</code></span>。从而得到矩阵 <span class="course-math" data-tex="\mathbf{A}" data-display="false"><code>\mathbf{A}</code></span>。


## Gram-Schmidt 正交化
{: #section-4 }


若我们已经有了 <span class="course-math" data-tex="V" data-display="false"><code>V</code></span> 的一组基 <span class="course-math" data-tex="\{ \mathbf{a}_{1},\mathbf{a}_{2},\dots,\mathbf{a}_{n} \}" data-display="false"><code>\{ \mathbf{a}_{1},\mathbf{a}_{2},\dots,\mathbf{a}_{n} \}</code></span>，我们可以通过 Gram-Schmidt 正交化（Orthogonalization）求出 <span class="course-math" data-tex="V" data-display="false"><code>V</code></span> 的一组规范正交基 <span class="course-math" data-tex="\mathbf{q}_{1},\mathbf{q}_{2},\dots,\mathbf{q}_{n}" data-display="false"><code>\mathbf{q}_{1},\mathbf{q}_{2},\dots,\mathbf{q}_{n}</code></span>。
先把 <span class="course-math" data-tex="\mathbf{a}_{1}" data-display="false"><code>\mathbf{a}_{1}</code></span> 归一化：
  <span class="course-math course-math-display" data-tex="\mathbf{q}_{1}=\frac{\mathbf{a}_{1}}{\lVert \mathbf{a}_{1} \rVert}" data-display="true"><code>\mathbf{q}_{1}=\frac{\mathbf{a}_{1}}{\lVert \mathbf{a}_{1} \rVert}</code></span>
把 <span class="course-math" data-tex="\mathbf{a}_{2}" data-display="false"><code>\mathbf{a}_{2}</code></span> 去掉其投影到 <span class="course-math" data-tex="\mathbf{q}_{1}" data-display="false"><code>\mathbf{q}_{1}</code></span> 的部分，再归一化
<span class="course-math course-math-display" data-tex="\mathbf{q}_{2}=\frac{\mathbf{a}_{2}-(\mathbf{q}_{1}^{\top}\mathbf{a}_{2})\mathbf{q}_{1}}{\lVert \mathbf{a}_{2}-(\mathbf{q}_{1}^{\top}\mathbf{a}_{2})\mathbf{q}_{1}\rVert }" data-display="true"><code>\mathbf{q}_{2}=\frac{\mathbf{a}_{2}-(\mathbf{q}_{1}^{\top}\mathbf{a}_{2})\mathbf{q}_{1}}{\lVert \mathbf{a}_{2}-(\mathbf{q}_{1}^{\top}\mathbf{a}_{2})\mathbf{q}_{1}\rVert }</code></span>
循环往复，减去往前面所有（正交的）向量做的投影：
<span class="course-math course-math-display" data-tex="\mathbf{u}_{j+1}=\mathbf{a}_{j+1}-\sum_{i=1}^j (\mathbf{q}_{i}^{\top} \mathbf{a}_{j+1})\mathbf{q}_{i}" data-display="true"><code>\mathbf{u}_{j+1}=\mathbf{a}_{j+1}-\sum_{i=1}^j (\mathbf{q}_{i}^{\top} \mathbf{a}_{j+1})\mathbf{q}_{i}</code></span>
<span class="course-math course-math-display" data-tex="\mathbf{q}_{j+1}= \frac{\mathbf{u}_{j+1}}{\lVert \mathbf{u}_{j+1} \rVert }" data-display="true"><code>\mathbf{q}_{j+1}= \frac{\mathbf{u}_{j+1}}{\lVert \mathbf{u}_{j+1} \rVert }</code></span>
当然也可以到最后再做单位化，计算会简单一些。


### QR 分解
{: #section-5 }


<span class="course-math course-math-display" data-tex="\mathbf{A}=\begin{bmatrix}&#10;\mathbf{a}_{1} &amp; \mathbf{a}_{2} &amp; \dots &amp; \mathbf{a}_{n}&#10;\end{bmatrix}" data-display="true"><code>\mathbf{A}=\begin{bmatrix}&#10;\mathbf{a}_{1} &amp; \mathbf{a}_{2} &amp; \dots &amp; \mathbf{a}_{n}&#10;\end{bmatrix}</code></span>
<span class="course-math course-math-display" data-tex="\mathbf{Q}=\begin{bmatrix}&#10;\mathbf{q}_{1} &amp; \mathbf{q}_{2} &amp; \dots &amp; \mathbf{q}_{n}&#10;\end{bmatrix}" data-display="true"><code>\mathbf{Q}=\begin{bmatrix}&#10;\mathbf{q}_{1} &amp; \mathbf{q}_{2} &amp; \dots &amp; \mathbf{q}_{n}&#10;\end{bmatrix}</code></span>
这里有：
<span class="course-math course-math-display" data-tex="\begin{aligned}&#10;\mathbf{a}_{1}&amp;=\lVert \mathbf{a}_{1} \rVert \mathbf{q}_{1}= \mathbf{q}_{1}^{\top}\mathbf{a}_{1}\mathbf{q}_{1}\\&#10;\mathbf{a}_{2}&amp;=(\mathbf{q}_{1}^{\top}\mathbf{a}_{2})\mathbf{q}_{1}+(\mathbf{q}_{2}^{\top}\mathbf{a}_{2})\mathbf{q}_{2} \\&#10;\dots \\&#10;\mathbf{a}_{n}&amp;=\sum_{i=1}^n(\mathbf{q}_{i}^{\top}\mathbf{a}_{n})\mathbf{q}_{i}&#10;\end{aligned}" data-display="true"><code>\begin{aligned}&#10;\mathbf{a}_{1}&amp;=\lVert \mathbf{a}_{1} \rVert \mathbf{q}_{1}= \mathbf{q}_{1}^{\top}\mathbf{a}_{1}\mathbf{q}_{1}\\&#10;\mathbf{a}_{2}&amp;=(\mathbf{q}_{1}^{\top}\mathbf{a}_{2})\mathbf{q}_{1}+(\mathbf{q}_{2}^{\top}\mathbf{a}_{2})\mathbf{q}_{2} \\&#10;\dots \\&#10;\mathbf{a}_{n}&amp;=\sum_{i=1}^n(\mathbf{q}_{i}^{\top}\mathbf{a}_{n})\mathbf{q}_{i}&#10;\end{aligned}</code></span>
因此可以构造矩阵
<span class="course-math course-math-display" data-tex="\mathbf{R}=\begin{bmatrix}&#10;\mathbf{q}_{1}^{\top}\mathbf{a}_{1} &amp; \mathbf{q}_{1}^{\top}\mathbf{a}_{2} &amp; \dots &amp; \mathbf{q}_{1}^{\top}\mathbf{a}_{n} \\&#10;0 &amp; \mathbf{q}_{2}^{\top}\mathbf{a}_{2} &amp; \dots &amp; \mathbf{q}_{2}^{\top}\mathbf{a}_{n} \\&#10;0 &amp; 0 &amp; \dots &amp; \dots \\&#10;0 &amp; 0 &amp; 0 &amp; \mathbf{q}_{n}^{\top}\mathbf{a}_{n} \\&#10;\end{bmatrix}" data-display="true"><code>\mathbf{R}=\begin{bmatrix}&#10;\mathbf{q}_{1}^{\top}\mathbf{a}_{1} &amp; \mathbf{q}_{1}^{\top}\mathbf{a}_{2} &amp; \dots &amp; \mathbf{q}_{1}^{\top}\mathbf{a}_{n} \\&#10;0 &amp; \mathbf{q}_{2}^{\top}\mathbf{a}_{2} &amp; \dots &amp; \mathbf{q}_{2}^{\top}\mathbf{a}_{n} \\&#10;0 &amp; 0 &amp; \dots &amp; \dots \\&#10;0 &amp; 0 &amp; 0 &amp; \mathbf{q}_{n}^{\top}\mathbf{a}_{n} \\&#10;\end{bmatrix}</code></span>
使得 <span class="course-math" data-tex="\mathbf{A}=\mathbf{Q}\mathbf{R}" data-display="false"><code>\mathbf{A}=\mathbf{Q}\mathbf{R}</code></span>。也就是说，<span class="course-math" data-tex="\mathbf{R}" data-display="false"><code>\mathbf{R}</code></span> 的第 <span class="course-math" data-tex="i" data-display="false"><code>i</code></span> 列是 <span class="course-math" data-tex="\mathbf{A}" data-display="false"><code>\mathbf{A}</code></span> 的第 <span class="course-math" data-tex="i" data-display="false"><code>i</code></span> 列在 <span class="course-math" data-tex="\mathbf{q}_{1},\mathbf{q}_{2},\dots,\mathbf{q}_{i}" data-display="false"><code>\mathbf{q}_{1},\mathbf{q}_{2},\dots,\mathbf{q}_{i}</code></span> 做投影得到。也可以用 <span class="course-math" data-tex="\mathbf{R}=\mathbf{Q}^{\top}\mathbf{A}" data-display="false"><code>\mathbf{R}=\mathbf{Q}^{\top}\mathbf{A}</code></span> 来算。
这里 <span class="course-math" data-tex="\mathbf{A}" data-display="false"><code>\mathbf{A}</code></span> 是一个列线性无关的 <span class="course-math" data-tex="m\times n" data-display="false"><code>m\times n</code></span> 矩阵，<span class="course-math" data-tex="\mathbf{Q}" data-display="false"><code>\mathbf{Q}</code></span> 是列规范正交的 <span class="course-math" data-tex="m\times n" data-display="false"><code>m\times n</code></span> 矩阵，<span class="course-math" data-tex="\mathbf{R}" data-display="false"><code>\mathbf{R}</code></span> 是可逆的上三角矩阵。
（若 <span class="course-math" data-tex="m=n" data-display="false"><code>m=n</code></span>：任何可逆的矩阵可以分解成一个正交矩阵乘一个上三角矩阵。）

若 <span class="course-math" data-tex="\mathbf{A}=\mathbf{Q}\mathbf{R}" data-display="false"><code>\mathbf{A}=\mathbf{Q}\mathbf{R}</code></span>，则 <span class="course-math" data-tex="\mathbf{A}\mathbf{x}=\mathbf{b}" data-display="false"><code>\mathbf{A}\mathbf{x}=\mathbf{b}</code></span> 的最小平方解： <span class="course-math" data-tex="\mathbf{A}^{\top}\mathbf{A}=(\mathbf{Q}\mathbf{R})^{\top}(\mathbf{Q}\mathbf{R})=\mathbf{R}^{\top}\mathbf{R}" data-display="false"><code>\mathbf{A}^{\top}\mathbf{A}=(\mathbf{Q}\mathbf{R})^{\top}(\mathbf{Q}\mathbf{R})=\mathbf{R}^{\top}\mathbf{R}</code></span>，故方程 <span class="course-math" data-tex="\mathbf{A}^{\top}\mathbf{A}\hat{\mathbf{x}}=\mathbf{A}^{\top}\mathbf{b}" data-display="false"><code>\mathbf{A}^{\top}\mathbf{A}\hat{\mathbf{x}}=\mathbf{A}^{\top}\mathbf{b}</code></span> 化简为 <span class="course-math" data-tex="\mathbf{R}^{\top}\mathbf{R}\hat{\mathbf{x}}=\mathbf{R}^{\top}\mathbf{Q}^{\top}\mathbf{b}" data-display="false"><code>\mathbf{R}^{\top}\mathbf{R}\hat{\mathbf{x}}=\mathbf{R}^{\top}\mathbf{Q}^{\top}\mathbf{b}</code></span>，由于 <span class="course-math" data-tex="\mathbf{R}^{\top}" data-display="false"><code>\mathbf{R}^{\top}</code></span> 可逆，有：
<span class="course-math course-math-display" data-tex="\mathbf{R}\hat{\mathbf{x}}=\mathbf{Q}^{\top}\mathbf{b}" data-display="true"><code>\mathbf{R}\hat{\mathbf{x}}=\mathbf{Q}^{\top}\mathbf{b}</code></span> 这个方程比较好解，因为 <span class="course-math" data-tex="\mathbf{R}" data-display="false"><code>\mathbf{R}</code></span> 是上三角矩阵，只需回代即可。


## 内积
{: #section-6 }


定义抽象的向量空间中的内积 <span class="course-math" data-tex="\left\langle  \cdot, \cdot \right\rangle :V\times V\to \mathbb{R}" data-display="false"><code>\left\langle  \cdot, \cdot \right\rangle :V\times V\to \mathbb{R}</code></span>，要求满足：
- 对称性（Symmetric）：<span class="course-math" data-tex="\left\langle  \mathbf{v},\mathbf{w} \right\rangle  =\left\langle  \mathbf{w},\mathbf{v} \right\rangle" data-display="false"><code>\left\langle  \mathbf{v},\mathbf{w} \right\rangle  =\left\langle  \mathbf{w},\mathbf{v} \right\rangle</code></span>
- 双线性（Bilinear）：<span class="course-math" data-tex="\left\langle  c_{1}\mathbf{v}+c_{2}\mathbf{w},\mathbf{a} \right\rangle  = c_{1} \left\langle  \mathbf{v},\mathbf{a} \right\rangle  + c_{2}\left\langle  \mathbf{w},\mathbf{a} \right\rangle , \left\langle  \mathbf{a}, c_{1}\mathbf{v}+c_{2}\mathbf{w} \right\rangle  = c_{1}\left\langle  \mathbf{a},\mathbf{v} \right\rangle +c_{2}\left\langle  \mathbf{a},\mathbf{w} \right\rangle" data-display="false"><code>\left\langle  c_{1}\mathbf{v}+c_{2}\mathbf{w},\mathbf{a} \right\rangle  = c_{1} \left\langle  \mathbf{v},\mathbf{a} \right\rangle  + c_{2}\left\langle  \mathbf{w},\mathbf{a} \right\rangle , \left\langle  \mathbf{a}, c_{1}\mathbf{v}+c_{2}\mathbf{w} \right\rangle  = c_{1}\left\langle  \mathbf{a},\mathbf{v} \right\rangle +c_{2}\left\langle  \mathbf{a},\mathbf{w} \right\rangle</code></span>。
- 正定性（Positive-Definiteness）： <span class="course-math" data-tex="\left\langle  \mathbf{v},\mathbf{v} \right\rangle  \geq 0" data-display="false"><code>\left\langle  \mathbf{v},\mathbf{v} \right\rangle  \geq 0</code></span>, 且 <span class="course-math" data-tex="\mathbf{v}=\mathbf{0} \iff \left\langle  \mathbf{v},\mathbf{v} \right\rangle  = 0" data-display="false"><code>\mathbf{v}=\mathbf{0} \iff \left\langle  \mathbf{v},\mathbf{v} \right\rangle  = 0</code></span>


例如，对定义在 <span class="course-math" data-tex="[0,1]" data-display="false"><code>[0,1]</code></span> 上的 <span class="course-math" data-tex="f(t)" data-display="false"><code>f(t)</code></span>，要找其最佳拟合直线 <span class="course-math" data-tex="b=C+Dt" data-display="false"><code>b=C+Dt</code></span>，则需要让 <span class="course-math" data-tex="E^{2}=\int_{0}^1(f(t)-C-Dt)^{2}\,\mathrm{d}t" data-display="false"><code>E^{2}=\int_{0}^1(f(t)-C-Dt)^{2}\,\mathrm{d}t</code></span> 最小。
- 我们定义这里的内积为 <span class="course-math" data-tex="\left\langle  f,g \right\rangle  =\int_{0}^1f(t)g(t)\,\mathrm{d}t" data-display="false"><code>\left\langle  f,g \right\rangle  =\int_{0}^1f(t)g(t)\,\mathrm{d}t</code></span>。
- 让 <span class="course-math" data-tex="\mathbf{v}_{1}=f(t), \mathbf{v}_{2}=C\cdot 1+D \cdot t" data-display="false"><code>\mathbf{v}_{1}=f(t), \mathbf{v}_{2}=C\cdot 1+D \cdot t</code></span>，则要让 <span class="course-math" data-tex="\lVert \mathbf{v}_{1}-\mathbf{v}_{2} \rVert^{2}" data-display="false"><code>\lVert \mathbf{v}_{1}-\mathbf{v}_{2} \rVert^{2}</code></span> 最小。
- 这里 <span class="course-math" data-tex="\mathbf{v}_{2}" data-display="false"><code>\mathbf{v}_{2}</code></span> 在 <span class="course-math" data-tex="\{ 1,t \}" data-display="false"><code>\{ 1,t \}</code></span> 张成的平面内，故这个长度最小，需要 <span class="course-math" data-tex="\mathbf{v}_{2}" data-display="false"><code>\mathbf{v}_{2}</code></span> 为 <span class="course-math" data-tex="\mathbf{v}_{1}" data-display="false"><code>\mathbf{v}_{1}</code></span> 在这个平面上的投影。
- 用 Gram-Schmidt 正交化可以找到一组正交基 <span class="course-math" data-tex="\mathbf{a}_{1}=  1, \mathbf{a}_{2}=t-\frac{1}{2}" data-display="false"><code>\mathbf{a}_{1}=  1, \mathbf{a}_{2}=t-\frac{1}{2}</code></span> 。
- 于是这个投影就是  
<span class="course-math course-math-display" data-tex="\frac{\left\langle  \mathbf{a}_{1}, \mathbf{v}_1 \right\rangle  }{\left\langle  \mathbf{a}_{1}, \mathbf{a}_{1} \right\rangle  } \mathbf{a}_{1}+ \frac{\left\langle  \mathbf{a}_{2},\mathbf{v}_1 \right\rangle  }{\left\langle  \mathbf{a}_{2},\mathbf{a}_{2} \right\rangle  } \mathbf{a}_{2}" data-display="true"><code>\frac{\left\langle  \mathbf{a}_{1}, \mathbf{v}_1 \right\rangle  }{\left\langle  \mathbf{a}_{1}, \mathbf{a}_{1} \right\rangle  } \mathbf{a}_{1}+ \frac{\left\langle  \mathbf{a}_{2},\mathbf{v}_1 \right\rangle  }{\left\langle  \mathbf{a}_{2},\mathbf{a}_{2} \right\rangle  } \mathbf{a}_{2}</code></span>
- 这也就是要找的直线。
