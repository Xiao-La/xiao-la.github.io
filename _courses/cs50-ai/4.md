## Loss Function
{: #section-6 }


Quantifying the utility lost by the prediction.

For classification problems, it is a **0-1 Loss Function:**
<span class="course-math course-math-display" data-tex="L(\text{actual}, \text{predicted}) = \begin{cases}&#10;0 &amp; \text{if actual = predicted} \\&#10;1 &amp; \text{otehrwise}&#10;\end{cases}" data-display="true"><code>L(\text{actual}, \text{predicted}) = \begin{cases}&#10;0 &amp; \text{if actual = predicted} \\&#10;1 &amp; \text{otehrwise}&#10;\end{cases}</code></span>
For regression problems, it may be:
<span class="course-math course-math-display" data-tex="L_{1}(\text{actual}, \text{predicted}) = \lvert \text{actual} - \text{predicted} \rvert" data-display="true"><code>L_{1}(\text{actual}, \text{predicted}) = \lvert \text{actual} - \text{predicted} \rvert</code></span>
<span class="course-math course-math-display" data-tex="L_{2}(\text{actual}, \text{predicted}) = (\text{actual} - \text{predicted})^{2}" data-display="true"><code>L_{2}(\text{actual}, \text{predicted}) = (\text{actual} - \text{predicted})^{2}</code></span>

## Overfitting
{: #section-7 }


A model fits the training data too well to generalize to other data set.


## Regularization
{: #section-8 }


To avoid overfitting:
1. Minimizing Cost (<span class="course-math" data-tex="h" data-display="false"><code>h</code></span>)=Loss (<span class="course-math" data-tex="h" data-display="false"><code>h</code></span>)+ <span class="course-math" data-tex="\lambda" data-display="false"><code>\lambda</code></span> Complexity (<span class="course-math" data-tex="h" data-display="false"><code>h</code></span>) 
2. Holdout cross-validation: split data into a training set and a test set
3. K-fold cross-validation: split data into k sets and experimenting k times, each time leaving out one dataset and using it as a test set


## Reinforcement Learning
{: #section-9 }


Given a set of rewards or punishments, learn what actions to take in the future.

<img class="course-image" src="{% endraw %}{{ '/assets/courses/%E7%AC%94%E8%AE%B0%E4%BE%9D%E8%B5%96/%E5%9B%BE%E7%89%87/4%20-%20Learning-5.png' | relative_url }}{% raw %}" alt="4 - Learning-5" width="497" height="249" loading="lazy" decoding="async">

Markov Decision Processes：
- Set of states **_S_**
- Set of actions **_Actions (S)_**
- Transition model **_P (s’ &#124; s, a)_**
- Reward function **_R (s, a, s’)_**

Q-Learning：
<span class="course-math" data-tex="Q(s,a)" data-display="false"><code>Q(s,a)</code></span> outputs an estimate of the value of taking action _a_ in state _s_.
Start with <span class="course-math" data-tex="Q(s,a)=0" data-display="false"><code>Q(s,a)=0</code></span> for all <span class="course-math" data-tex="s,a" data-display="false"><code>s,a</code></span>.
Every time we take an action <span class="course-math" data-tex="a" data-display="false"><code>a</code></span>  in state <span class="course-math" data-tex="s" data-display="false"><code>s</code></span> and observe a reward <span class="course-math" data-tex="r" data-display="false"><code>r</code></span>, we update:
<span class="course-math course-math-display" data-tex="Q(s,a)\gets Q(s,a)+\alpha ((r+\gamma \max_{a&#x27;}Q(s&#x27;,a&#x27;))-Q(s,a))" data-display="true"><code>Q(s,a)\gets Q(s,a)+\alpha ((r+\gamma \max_{a&#x27;}Q(s&#x27;,a&#x27;))-Q(s,a))</code></span>
Here <span class="course-math" data-tex="\alpha" data-display="false"><code>\alpha</code></span> is the learning rate.

Greedy Decision-Making: Choose the maximum <span class="course-math" data-tex="Q(s,a)" data-display="false"><code>Q(s,a)</code></span>.
To let the model do some exploring, we use <span class="course-math" data-tex="\varepsilon" data-display="false"><code>\varepsilon</code></span> -greedy : With probability <span class="course-math" data-tex="1-\varepsilon" data-display="false"><code>1-\varepsilon</code></span>, choose estimated best move, and with probability <span class="course-math" data-tex="\varepsilon" data-display="false"><code>\varepsilon</code></span>, choose a random move.

Function Approximation: to approximate <span class="course-math" data-tex="Q(s,a)" data-display="false"><code>Q(s,a)</code></span>.


## Unsupervised Learning
{: #section-10 }


Given input data without any additional feedback, learn patterns.

Clustering: organizing a set of objects into groups in such a way that similar objects tend to be in the same group.

K-means clustering:                                                                   
<img class="course-image" src="{% endraw %}{{ '/assets/courses/%E7%AC%94%E8%AE%B0%E4%BE%9D%E8%B5%96/%E5%9B%BE%E7%89%87/4%20-%20Learning-6.png' | relative_url }}{% raw %}" alt="4 - Learning-6" width="2012" height="346" loading="lazy" decoding="async">
Set k cluster centers. 
Assign each point with the value of the closest center.
Move the centers to the middle of the corresponding points.
Keep iterating until it reaches an equilibrium.
