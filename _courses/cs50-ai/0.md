### Search Problem
{: #section-1 }


Concepts: Agent（智能体）, State（状态） (Initial State（初始状态）), Actions（动作）, Transition Model（转移模型）, State Space（状态空间）, Goal Test（目标测试）, Path Cost（路径代价）.

>  **Transition Model（转移模型）:** A function <span class="course-math" data-tex="\text{Result(s, a)}" data-display="false"><code>\text{Result(s, a)}</code></span> returns the state resulting from performing action <span class="course-math" data-tex="\text{a}" data-display="false"><code>\text{a}</code></span> in state <span class="course-math" data-tex="\text{s}" data-display="false"><code>\text{s}</code></span>.

### Solving Search Problem
{: #section-2 }


Concepts: Solution（解） (Optimal Solution（最优解）), Node（节点）, Frontier（前沿/边界）

>  **Frontier（前沿/边界）:** the mechanism that “manages” the _nodes_. 

Search Processes: Repeat
1. If the frontier is empty: Stop. There is no solution to the problem.
2. Remove a node from the frontier. This is the node that will be considered.
3. If the node contains the goal state: Return the solution. Stop.
    Else,
    - Add the current state to the explored set. Expand the node and add successor states that are neither explored nor already in the frontier.
    * The explored set（已探索集合）stores states.

### Depth-First Search, DFS（深度优先搜索）
{: #section-3 }


DFS uses a **stack（栈）** as the frontier.


### Breadth-First Search, BFS（广度优先搜索）
{: #section-4 }


BFS uses a **queue（队列）** as the frontier.

>  Guaranteed to find the shortest path in number of steps; optimal in path cost when every step has the same positive cost（每步代价相同时保证最优）.


### Greedy Best-First Search, GBFS（贪心最佳优先搜索）
{: #section-5 }


Concepts: Uninformed / Informed Search Algorithm（无信息/有信息〔启发式〕搜索算法）.

>  **Informed Search Algorithm（有信息/启发式搜索算法）**: Consider additional knowledge to improve its performance.

GBFS expands node with lowest value of <span class="course-math" data-tex="h(n)" data-display="false"><code>h(n)</code></span>.

<span class="course-math" data-tex="h(n)=\text{estimate cost to goal}" data-display="false"><code>h(n)=\text{estimate cost to goal}</code></span>

>  Not guaranteed to find the optimal solution（不保证找到最优解）.


### A* Search（A* 搜索）
{: #section-6 }


A* search expands node with lowest value of <span class="course-math" data-tex="h(n)+g(n)" data-display="false"><code>h(n)+g(n)</code></span>. 

<span class="course-math" data-tex="g(n)=\text{cost to reach node}" data-display="false"><code>g(n)=\text{cost to reach node}</code></span> 

- <span class="course-math" data-tex="h(n)" data-display="false"><code>h(n)</code></span> is **admissive（可采纳）** if <span class="course-math" data-tex="0\leq h(n)\leq h^*(n)" data-display="false"><code>0\leq h(n)\leq h^*(n)</code></span> (<span class="course-math" data-tex="h^*(n)" data-display="false"><code>h^*(n)</code></span> is the real cost to goal).
- <span class="course-math" data-tex="h(n)" data-display="false"><code>h(n)</code></span> is **consistent（一致的）** if <span class="course-math" data-tex="h(n)\leq h(n&#x27;)+\text{cost}(n\to n&#x27;)" data-display="false"><code>h(n)\leq h(n&#x27;)+\text{cost}(n\to n&#x27;)</code></span>.

>  A* search is optimal（最优） if <span class="course-math" data-tex="h(n)" data-display="false"><code>h(n)</code></span> is admissive and consistent.

### Minimax & Alpha-Beta Pruning（极大极小与 α-β 剪枝）
{: #section-7 }


Concepts: Adversarial Search（对抗搜索）

#### Game（博弈）
{: #section-8 }


- Initial State <span class="course-math" data-tex="S_{0}" data-display="false"><code>S_{0}</code></span>（初始状态）
- <span class="course-math" data-tex="\text{Player}(s)" data-display="false"><code>\text{Player}(s)</code></span>（玩家）, <span class="course-math" data-tex="\text{Actions}(s)" data-display="false"><code>\text{Actions}(s)</code></span>（动作）, <span class="course-math" data-tex="\text{Result}(s, a)" data-display="false"><code>\text{Result}(s, a)</code></span>（结果/转移）, <span class="course-math" data-tex="\text{Terminal}(s)" data-display="false"><code>\text{Terminal}(s)</code></span>（终止）, <span class="course-math" data-tex="\text{Utility}(s)" data-display="false"><code>\text{Utility}(s)</code></span>（效用）

#### Minimax（极大极小）
{: #section-9 }


Given a state <span class="course-math" data-tex="s" data-display="false"><code>s</code></span>

- The **maximizing player（最大化玩家）** picks action <span class="course-math" data-tex="a" data-display="false"><code>a</code></span> in <span class="course-math" data-tex="\text{Actions}(s)" data-display="false"><code>\text{Actions}(s)</code></span> that produces the highest value of <span class="course-math" data-tex="\text{Min-Value}(\text{Result}(s, a))" data-display="false"><code>\text{Min-Value}(\text{Result}(s, a))</code></span>.
- The **minimizing player（最小化玩家）** picks action _a_ in <span class="course-math" data-tex="\text{Actions}(s)" data-display="false"><code>\text{Actions}(s)</code></span> that produces the lowest value of <span class="course-math" data-tex="\text{Max-Value}(\text{Result}(s, a))" data-display="false"><code>\text{Max-Value}(\text{Result}(s, a))</code></span>.


#### Alpha-Beta Pruning（α-β 剪枝）
{: #section-10 }


Keep tracking: 
- <span class="course-math" data-tex="\alpha" data-display="false"><code>\alpha</code></span>: The lower bound（下界） of the score that the maximizing player can reach.
- <span class="course-math" data-tex="\beta" data-display="false"><code>\beta</code></span>: The upper bound（上界） of the score that the minimizing player can reach.
If <span class="course-math" data-tex="\alpha \geq \beta" data-display="false"><code>\alpha \geq \beta</code></span> holds for a node, there is no need to expand the node any more.

<pre class="course-pseudocode">\begin{algorithm}
  \caption{Alpha-Beta Pruning}
  \begin{algorithmic}
    \Require{A node \texttt{u}, alpha bound \texttt{alph}, beta bound \texttt{beta}, a boolean \texttt{is\_max}, an evaluation function \texttt{Evaluate}}
    \Function{AlphaBeta}{\texttt{u}, \texttt{alph}, \texttt{beta}, \texttt{is\_max}}
      \If{\texttt{u} has no children}
        \State \Return \texttt{Evaluate(u)}
      \EndIf
      \If{\texttt{is\_max} = true}
        \ForAll{\texttt{child} of \texttt{u}}
          \State \texttt{alph} $\gets$ $\max(\texttt{alph}, \texttt{AlphaBeta(child, alph, beta, false)})$
          \If{\texttt{alph} $\ge$ \texttt{beta}}
            \Break
          \EndIf
        \EndFor
        \State \Return \texttt{alph}
      \Else
        \ForAll{\texttt{child} of \texttt{u}}
          \State \texttt{beta} $\gets$ $\min(\texttt{beta}, \texttt{AlphaBeta(child, alph, beta, true)})$
          \If{\texttt{alph} $\ge$ \texttt{beta}}
            \Break
          \EndIf
        \EndFor
        \State \Return \texttt{beta}
      \EndIf
    \EndFunction
  \end{algorithmic}
\end{algorithm}
