<span class="course-math" data-tex="L\times L\times L" data-display="false"><code>L\times L\times L</code></span> 正方体内的气体与一面墙碰撞：
<span class="course-math course-math-display" data-tex="-mv_{x}-mv_{x}=\bar{F_{x}} \frac{2L}{v_{x}}" data-display="true"><code>-mv_{x}-mv_{x}=\bar{F_{x}} \frac{2L}{v_{x}}</code></span>
取分子撞向该墙的方向为正，墙对分子的平均力为：
<span class="course-math course-math-display" data-tex="\bar{F_{x}}=-\frac{mv_{x}^2}{L}" data-display="true"><code>\bar{F_{x}}=-\frac{mv_{x}^2}{L}</code></span>
墙受到方向相反的反作用力，其合力的大小为
<span class="course-math course-math-display" data-tex="\begin{aligned}&#10;\bar{F}&amp;= F_{1x}+F_{2x}+\dots+F_{Nx} \\&#10;&amp;=\frac{m}{L} (v_{1x}^2+v_{2x}^2+\dots+v_{Nx}^2) \\&#10;&amp;=\frac{nM}{L}(v_{x}^2)_{\mathrm{avg}}&#10;\end{aligned}" data-display="true"><code>\begin{aligned}&#10;\bar{F}&amp;= F_{1x}+F_{2x}+\dots+F_{Nx} \\&#10;&amp;=\frac{m}{L} (v_{1x}^2+v_{2x}^2+\dots+v_{Nx}^2) \\&#10;&amp;=\frac{nM}{L}(v_{x}^2)_{\mathrm{avg}}&#10;\end{aligned}</code></span>
而气体具有各向同性，也就是说 <span class="course-math" data-tex="(v_{x}^2)_{\mathrm{avg}}=(v_{y}^2)_{\mathrm{avg}}=(v_{z}^2)_{\mathrm{avg}}=\frac{1}{3}(v^2)_{\mathrm{avg}}" data-display="false"><code>(v_{x}^2)_{\mathrm{avg}}=(v_{y}^2)_{\mathrm{avg}}=(v_{z}^2)_{\mathrm{avg}}=\frac{1}{3}(v^2)_{\mathrm{avg}}</code></span>。

那么 <span class="course-math" data-tex="\bar{F}=\frac{nM}{3L}(v^2)_{\mathrm{avg}}" data-display="false"><code>\bar{F}=\frac{nM}{3L}(v^2)_{\mathrm{avg}}</code></span>

那么压强

<span class="course-math course-math-display" data-tex="\bar{p}= \frac{\bar{F}}{A}=\frac{nM}{3V}(v^2)_{\mathrm{avg}}=\frac{nM}{3V}v_{\mathrm{rms}}^2" data-display="true"><code>\bar{p}= \frac{\bar{F}}{A}=\frac{nM}{3V}(v^2)_{\mathrm{avg}}=\frac{nM}{3V}v_{\mathrm{rms}}^2</code></span>
 其中 <span class="course-math" data-tex="v_{\mathrm{rms}}=\sqrt{ (v^{2})_{\mathrm{avg}} }" data-display="false"><code>v_{\mathrm{rms}}=\sqrt{ (v^{2})_{\mathrm{avg}} }</code></span>
从而
<span class="course-math course-math-display" data-tex="pV=\frac{nM}{3}v_{\mathrm{rms}}^2=nRT" data-display="true"><code>pV=\frac{nM}{3}v_{\mathrm{rms}}^2=nRT</code></span>
也就是说
<span class="course-math course-math-display" data-tex="v_{\mathrm{rms}}=\sqrt{ \frac{3RT}{M} }" data-display="true"><code>v_{\mathrm{rms}}=\sqrt{ \frac{3RT}{M} }</code></span>
所以平动动能：
<span class="course-math course-math-display" data-tex="\bar{K}=\frac{1}{2}m (v^2)_{\mathrm{avg}}=\frac{1}{2}mv_{\mathrm{rms}}^2=\frac{3}{2} \frac{m}{M}RT=\frac{3}{2}kT" data-display="true"><code>\bar{K}=\frac{1}{2}m (v^2)_{\mathrm{avg}}=\frac{1}{2}mv_{\mathrm{rms}}^2=\frac{3}{2} \frac{m}{M}RT=\frac{3}{2}kT</code></span>
