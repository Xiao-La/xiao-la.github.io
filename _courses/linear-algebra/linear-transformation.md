线性变换将一个向量空间映射到另一个向量空间 <span class="course-math" data-tex="T:V\to W" data-display="false"><code>T:V\to W</code></span>，它满足这两个条件：
<span class="course-math course-math-display" data-tex="\text{1. }T(\boldsymbol{a}+\boldsymbol{b})=T(\boldsymbol{a})+T(\boldsymbol{b})" data-display="true"><code>\text{1. }T(\boldsymbol{a}+\boldsymbol{b})=T(\boldsymbol{a})+T(\boldsymbol{b})</code></span>
<span class="course-math course-math-display" data-tex="\text{2. }T(k\boldsymbol{a})=kT(\boldsymbol{a})" data-display="true"><code>\text{2. }T(k\boldsymbol{a})=kT(\boldsymbol{a})</code></span>
线性变换可以用矩阵表示，其定义如下：
设 <span class="course-math" data-tex="V" data-display="false"><code>V</code></span> 和 <span class="course-math" data-tex="W" data-display="false"><code>W</code></span> 是同一个数域 <span class="course-math" data-tex="F" data-display="false"><code>F</code></span> 上的有限维向量空间，且 <span class="course-math" data-tex="\dim(V) = n" data-display="false"><code>\dim(V) = n</code></span>，<span class="course-math" data-tex="\dim(W) = m" data-display="false"><code>\dim(W) = m</code></span>。设 <span class="course-math" data-tex="T: V \to W" data-display="false"><code>T: V \to W</code></span> 是一个从 <span class="course-math" data-tex="V" data-display="false"><code>V</code></span> 到 <span class="course-math" data-tex="W" data-display="false"><code>W</code></span> 的线性变换。设 <span class="course-math" data-tex="\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \dots, \boldsymbol{\alpha}_n" data-display="false"><code>\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \dots, \boldsymbol{\alpha}_n</code></span> 是定义域 <span class="course-math" data-tex="V" data-display="false"><code>V</code></span> 的一组基， <span class="course-math" data-tex="\boldsymbol{\beta}_1, \boldsymbol{\beta}_2, \dots, \boldsymbol{\beta}_m" data-display="false"><code>\boldsymbol{\beta}_1, \boldsymbol{\beta}_2, \dots, \boldsymbol{\beta}_m</code></span> 是目标域 <span class="course-math" data-tex="W" data-display="false"><code>W</code></span> 的一组基。那么 <span class="course-math" data-tex="T(\boldsymbol{\alpha}_j)" data-display="false"><code>T(\boldsymbol{\alpha}_j)</code></span> 可以唯一地表示为这些基向量的线性组合：
<span class="course-math course-math-display" data-tex="T(\boldsymbol{\alpha}_j) = a_{1j}\boldsymbol{\beta}_1 + a_{2j}\boldsymbol{\beta}_2 + \dots + a_{mj}\boldsymbol{\beta}_m = \sum_{i=1}^m a_{ij}\boldsymbol{\beta}_i" data-display="true"><code>T(\boldsymbol{\alpha}_j) = a_{1j}\boldsymbol{\beta}_1 + a_{2j}\boldsymbol{\beta}_2 + \dots + a_{mj}\boldsymbol{\beta}_m = \sum_{i=1}^m a_{ij}\boldsymbol{\beta}_i</code></span>
我们将上述 <span class="course-math" data-tex="n" data-display="false"><code>n</code></span> 个等式（<span class="course-math" data-tex="j=1, 2, \dots, n" data-display="false"><code>j=1, 2, \dots, n</code></span>）中的系数 <span class="course-math" data-tex="a_{ij}" data-display="false"><code>a_{ij}</code></span> 排列成一个 <span class="course-math" data-tex="m \times n" data-display="false"><code>m \times n</code></span> 的矩阵 <span class="course-math" data-tex="A" data-display="false"><code>A</code></span>。具体来说，把 <span class="course-math" data-tex="T(\boldsymbol{\alpha}_j)" data-display="false"><code>T(\boldsymbol{\alpha}_j)</code></span> 在基 <span class="course-math" data-tex="\beta" data-display="false"><code>\beta</code></span> 下的坐标列向量作为矩阵 <span class="course-math" data-tex="A" data-display="false"><code>A</code></span> 的第 <span class="course-math" data-tex="j" data-display="false"><code>j</code></span> 列：

<span class="course-math course-math-display" data-tex="A = \begin{pmatrix}&#10;a_{11} &amp; a_{12} &amp; \dots &amp; a_{1n} \\&#10;a_{21} &amp; a_{22} &amp; \dots &amp; a_{2n} \\&#10;\vdots &amp; \vdots &amp; \ddots &amp; \vdots \\&#10;a_{m1} &amp; a_{m2} &amp; \dots &amp; a_{mn}&#10;\end{pmatrix}" data-display="true"><code>A = \begin{pmatrix}&#10;a_{11} &amp; a_{12} &amp; \dots &amp; a_{1n} \\&#10;a_{21} &amp; a_{22} &amp; \dots &amp; a_{2n} \\&#10;\vdots &amp; \vdots &amp; \ddots &amp; \vdots \\&#10;a_{m1} &amp; a_{m2} &amp; \dots &amp; a_{mn}&#10;\end{pmatrix}</code></span>

这个矩阵 <span class="course-math" data-tex="A" data-display="false"><code>A</code></span> 就称为**线性变换 <span class="course-math" data-tex="T" data-display="false"><code>T</code></span> 在基 <span class="course-math" data-tex="\alpha" data-display="false"><code>\alpha</code></span> 和基 <span class="course-math" data-tex="\beta" data-display="false"><code>\beta</code></span> 下的矩阵表示**。
上述关系通常可以用分块矩阵的形式简记为：
<span class="course-math course-math-display" data-tex="T(\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \dots, \boldsymbol{\alpha}_n) = (\boldsymbol{\beta}_1, \boldsymbol{\beta}_2, \dots, \boldsymbol{\beta}_m) A" data-display="true"><code>T(\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \dots, \boldsymbol{\alpha}_n) = (\boldsymbol{\beta}_1, \boldsymbol{\beta}_2, \dots, \boldsymbol{\beta}_m) A</code></span>

矩阵表示的意义：如果 <span class="course-math" data-tex="V" data-display="false"><code>V</code></span> 中的向量 <span class="course-math" data-tex="\boldsymbol{v}" data-display="false"><code>\boldsymbol{v}</code></span> 在基 <span class="course-math" data-tex="\alpha" data-display="false"><code>\alpha</code></span> 下的坐标列向量为 <span class="course-math" data-tex="\boldsymbol{x} = (x_1, x_2, \dots, x_n)^{\top}" data-display="false"><code>\boldsymbol{x} = (x_1, x_2, \dots, x_n)^{\top}</code></span>；其像 <span class="course-math" data-tex="T(\boldsymbol{v})" data-display="false"><code>T(\boldsymbol{v})</code></span> 在 <span class="course-math" data-tex="W" data-display="false"><code>W</code></span> 的基 <span class="course-math" data-tex="\beta" data-display="false"><code>\beta</code></span> 下的坐标列向量为 <span class="course-math" data-tex="\boldsymbol{y} = (y_1, y_2, \dots, y_m)^{\top}" data-display="false"><code>\boldsymbol{y} = (y_1, y_2, \dots, y_m)^{\top}</code></span>。那么，抽象的线性变换 <span class="course-math" data-tex="T(\boldsymbol{v})" data-display="false"><code>T(\boldsymbol{v})</code></span> 等价于其坐标向的矩阵乘法 <span class="course-math" data-tex="\boldsymbol{y} = A\boldsymbol{x}" data-display="false"><code>\boldsymbol{y} = A\boldsymbol{x}</code></span>。



**旋转矩阵**
<span class="course-math course-math-display" data-tex="T_{\theta}=\begin{bmatrix}&#10;\cos\theta &amp; -\sin\theta \\&#10;\sin\theta &amp; \cos\theta&#10;\end{bmatrix}" data-display="true"><code>T_{\theta}=\begin{bmatrix}&#10;\cos\theta &amp; -\sin\theta \\&#10;\sin\theta &amp; \cos\theta&#10;\end{bmatrix}</code></span>
表示将 <span class="course-math" data-tex="\mathbb{R}^{2}" data-display="false"><code>\mathbb{R}^{2}</code></span> 的基向量 <span class="course-math" data-tex="\boldsymbol{i}=(1,0),\boldsymbol{j}=(0,1)" data-display="false"><code>\boldsymbol{i}=(1,0),\boldsymbol{j}=(0,1)</code></span> 绕原点逆时针旋转 <span class="course-math" data-tex="\theta" data-display="false"><code>\theta</code></span> ：
<span class="course-math course-math-display" data-tex="\boldsymbol{i}&#x27;=T_{\theta}(\boldsymbol{i})=T_{\theta}\begin{bmatrix}&#10;1 \\&#10;0&#10;\end{bmatrix}=\begin{bmatrix}&#10;\cos\theta \\&#10;\sin\theta&#10;\end{bmatrix}" data-display="true"><code>\boldsymbol{i}&#x27;=T_{\theta}(\boldsymbol{i})=T_{\theta}\begin{bmatrix}&#10;1 \\&#10;0&#10;\end{bmatrix}=\begin{bmatrix}&#10;\cos\theta \\&#10;\sin\theta&#10;\end{bmatrix}</code></span>
<span class="course-math course-math-display" data-tex="\boldsymbol{j}&#x27;= T_{\theta}(\boldsymbol{j})=T_{\theta}\begin{bmatrix}&#10;0 \\&#10;1&#10;\end{bmatrix}&#10;=\begin{bmatrix}&#10;-\sin\theta \\&#10;\cos\theta&#10;\end{bmatrix}" data-display="true"><code>\boldsymbol{j}&#x27;= T_{\theta}(\boldsymbol{j})=T_{\theta}\begin{bmatrix}&#10;0 \\&#10;1&#10;\end{bmatrix}&#10;=\begin{bmatrix}&#10;-\sin\theta \\&#10;\cos\theta&#10;\end{bmatrix}</code></span>
**投影矩阵**
<span class="course-math course-math-display" data-tex="P_{\theta}=\begin{bmatrix}&#10;\cos ^{2}\theta &amp; \cos\theta \sin\theta \\&#10;\cos\theta \sin\theta &amp; \sin ^{2}\theta&#10;\end{bmatrix}" data-display="true"><code>P_{\theta}=\begin{bmatrix}&#10;\cos ^{2}\theta &amp; \cos\theta \sin\theta \\&#10;\cos\theta \sin\theta &amp; \sin ^{2}\theta&#10;\end{bmatrix}</code></span>
表示将 <span class="course-math" data-tex="\mathbb{R}^{2}" data-display="false"><code>\mathbb{R}^{2}</code></span> 的基向量 <span class="course-math" data-tex="\boldsymbol{i}=(1,0),\boldsymbol{j}=(0,1)" data-display="false"><code>\boldsymbol{i}=(1,0),\boldsymbol{j}=(0,1)</code></span> 投影到 <span class="course-math" data-tex="\boldsymbol{v}=(\cos\theta, \sin\theta)" data-display="false"><code>\boldsymbol{v}=(\cos\theta, \sin\theta)</code></span> 上。

**反射矩阵**
<span class="course-math" data-tex="R_{\theta}:\mathbb{R}^{2}\to \mathbb{R}^{2}" data-display="false"><code>R_{\theta}:\mathbb{R}^{2}\to \mathbb{R}^{2}</code></span> 表示向量由 <span class="course-math" data-tex="\boldsymbol{v}=(\cos\theta, \sin\theta)" data-display="false"><code>\boldsymbol{v}=(\cos\theta, \sin\theta)</code></span> 反射。由几何关系有
<span class="course-math course-math-display" data-tex="R_{\theta}(\boldsymbol{v})+\boldsymbol{v}=2P_{\theta}(\boldsymbol{v})" data-display="true"><code>R_{\theta}(\boldsymbol{v})+\boldsymbol{v}=2P_{\theta}(\boldsymbol{v})</code></span>
那么就有
<span class="course-math course-math-display" data-tex="R_{\theta}=2P_{\theta}-I=\begin{bmatrix}&#10;\cos(2\theta) &amp; \sin(2\theta) \\&#10;\sin(2\theta) &amp; -\cos(2\theta)&#10;\end{bmatrix}" data-display="true"><code>R_{\theta}=2P_{\theta}-I=\begin{bmatrix}&#10;\cos(2\theta) &amp; \sin(2\theta) \\&#10;\sin(2\theta) &amp; -\cos(2\theta)&#10;\end{bmatrix}</code></span>

这里的变换矩阵和**基的选取**有关。
线性变换的变换基（Change of basis）：若 <span class="course-math" data-tex="T:V\to V" data-display="false"><code>T:V\to V</code></span> 是一个线性变换，而 <span class="course-math" data-tex="A" data-display="false"><code>A</code></span> 是 <span class="course-math" data-tex="T" data-display="false"><code>T</code></span> 在基 <span class="course-math" data-tex="\boldsymbol{v}_{1}, \dots, \boldsymbol{v}_{n}" data-display="false"><code>\boldsymbol{v}_{1}, \dots, \boldsymbol{v}_{n}</code></span> 下的矩阵表示，<span class="course-math" data-tex="B" data-display="false"><code>B</code></span> 是 <span class="course-math" data-tex="T" data-display="false"><code>T</code></span>  在基 <span class="course-math" data-tex="\boldsymbol{w}_{1},\dots, \boldsymbol{w}_{n}" data-display="false"><code>\boldsymbol{w}_{1},\dots, \boldsymbol{w}_{n}</code></span> 下的矩阵表示。
若 <span class="course-math" data-tex="\begin{bmatrix}\boldsymbol{w}_{1} \dots \boldsymbol{w}_{n}\end{bmatrix}=\begin{bmatrix}\boldsymbol{v}_{1}\dots \boldsymbol{v}_{n}\end{bmatrix}S" data-display="false"><code>\begin{bmatrix}\boldsymbol{w}_{1} \dots \boldsymbol{w}_{n}\end{bmatrix}=\begin{bmatrix}\boldsymbol{v}_{1}\dots \boldsymbol{v}_{n}\end{bmatrix}S</code></span>，则有 <span class="course-math" data-tex="B=S^{-1}AS" data-display="false"><code>B=S^{-1}AS</code></span>。

**理解：** <span class="course-math" data-tex="W\boldsymbol{x}=V(S\boldsymbol{x})" data-display="false"><code>W\boldsymbol{x}=V(S\boldsymbol{x})</code></span>。也就是说，<span class="course-math" data-tex="W" data-display="false"><code>W</code></span> 基下的坐标 <span class="course-math" data-tex="\boldsymbol{x}" data-display="false"><code>\boldsymbol{x}</code></span> 对应 <span class="course-math" data-tex="V" data-display="false"><code>V</code></span> 基下的坐标 <span class="course-math" data-tex="S\boldsymbol{x}" data-display="false"><code>S\boldsymbol{x}</code></span>！所以，在基 <span class="course-math" data-tex="W" data-display="false"><code>W</code></span> 下，线性变换的矩阵表示为 <span class="course-math" data-tex="\boldsymbol{y}=B\boldsymbol{x}" data-display="false"><code>\boldsymbol{y}=B\boldsymbol{x}</code></span>，这里 <span class="course-math" data-tex="\boldsymbol{x},\boldsymbol{y}" data-display="false"><code>\boldsymbol{x},\boldsymbol{y}</code></span> 都是 <span class="course-math" data-tex="W" data-display="false"><code>W</code></span> 基下的坐标。把 <span class="course-math" data-tex="\boldsymbol{y}=B\boldsymbol{x}" data-display="false"><code>\boldsymbol{y}=B\boldsymbol{x}</code></span> 翻译成 <span class="course-math" data-tex="V" data-display="false"><code>V</code></span> 基下的坐标：<span class="course-math" data-tex="S\boldsymbol{y}=A(S\boldsymbol{x})" data-display="false"><code>S\boldsymbol{y}=A(S\boldsymbol{x})</code></span>！对比一下，就可以得到 <span class="course-math" data-tex="B=S^{-1}AS" data-display="false"><code>B=S^{-1}AS</code></span>！
